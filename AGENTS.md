## Вид — коротко

Решения автора курса сильнее правила №1. Полностью, с замерами и датами, — в `docs/agents/visual-decisions.md`.

- Канва белая `#FFFFFF`; нейтральные оттенки холодные, с фиолетовым подтоном.
- Высота вместо обводки: карточки на тенях `--shadow-card`, `--shadow-1…3`, скругления `--r1…--r4`. Рамка 1px — только у узлов диаграмм, таблиц и полей ввода.
- Размер шрифта — **только ступенями** `--fs-1…--fs-8`, `--fs-h1…--fs-h3`; пикселей в `font-size` нет. Масштаб — `--fs-scale` в `theme.ts`.
- Проза одним размером: лид раздела, абзацы, списки, текст карточек и `DarkText` — `--fs-6`, интерлиньяж 1.6. Крупнее — только заголовки и описание под названием темы.
- Текст на всю ширину колонки, без ограничений в `ch` (кроме H1).
- Проза во всю колонку — **по ширине, с переносами**. Карточки в сетках — по левому краю.
- Мелкий текст не ниже `--fs-2`.
- Код в строке — IBM Plex Mono `0.92em` на подложке `--surface-3`. Тёмный контейнер с прозой обязан снять подложку: `--inline-code-bg: transparent`.
- «Погашенная» карточка выделяется подложкой, а не бледным текстом: текст `--prose`, заголовок `--text-muted`.
- Сетка карточек с кодом — в один столбец (`.grid:has(pre)`).
- График не ужимается ниже ширины `viewBox`, на узком экране прокручивается в своей рамке.
- Контраст `--dim`/`--ghost` — по WCAG на всех трёх фонах курса. Новый `<input>` получает `font: inherit; color: inherit`.
- Никаких новых цветов и шрифтов мимо `shared/ui/theme.ts` (сторожит `palette.spec`).

## Текст — коротко

Полностью, с примерами и историей, — в `docs/agents/writing-rules.md` и `docs/agents/lesson-structure.md`.

- Абзац, который описывает устройство страницы, удаляется: пересказ порядка блоков, объяснение, зачем нужен раздел, «чего знать не нужно», повтор лида. Проверка: что читатель узнает **о предмете**?
- Подпись к демо говорит, что увидеть и почему, а не какие там органы управления. Без «слева/справа».
- «Проверено запуском» — не для читателя. Этому место в докстринге `data.ts` и тесте.
- Внутри темы на раздел ссылаются по **имени**, а не по номеру. На другие темы — ссылкой с именем темы, без «предыдущий урок».
- Демо не показывает объект, исходника которого в теме нет. Сквозной пример стоит выше, в одном экземпляре.
- Код примера — строка в `data.ts`, печатается `CodeBlock` и исполняется тестом: тот же код, не копия.
- Где термин нельзя убрать, рядом ставится врезка `<Card tone="info" color="tone" text={PLAIN_*} />`. **Без ярлыка «на пальцах»**, текст — пропом, ставится там, где понятие встречается впервые.
- «Подробнее — в теме X» должно вести туда, где это действительно разобрано. Ссылка-заглушка на оглавление направления недопустима.
- Строчную разметку разбирает только `inlineMd`. Таблица «откуда текст → как выводить» — в `docs/agents/lesson-structure.md`.
- В MDX нельзя `<style>`.
- Обязательные блоки темы: словарь, «Перед началом» (`s0`), источники и смежное. Тонкие места и «за кадром» необязательны. Сторожит `topic-anatomy.test.ts`.

## Команды

```bash
npm run dev      # дев-сервер — это ДЕМОН: управлять через npx astro dev status|logs|stop
npm run build
npm run check    # astro check + vue-tsc
npm test         # vitest
npm run e2e      # playwright (предпросмотр на 4329 поднимает global-setup)
npm run lint     # eslint: границы слоёв и шов к библиотеке
```

Пока правите тему, гоняйте только её тесты (`npx vitest run tests/unit/<тема>.test.ts`). Полный `npm test` и `npm run e2e` — один раз, перед коммитом.

Новое поле во frontmatter подхватывается только после `npx astro dev stop && rm -rf .astro`. Остальные ловушки — в `docs/agents/stack.md`.

## Слои (FSD) — коротко

`pages → widgets → features → entities → shared`, импорт только вниз. Виджет не импортирует виджет, фича — фичу.
Компоненты Aura — только через `@/shared/ui`, никогда напрямую из `@ilomee/*`. `.astro` не реэкспортируется через `index.ts`.
Тема живёт в `src/content/<коллекция>/<slug>/`: `index.mdx` + `data.ts`. Подробно — `docs/agents/architecture.md`.

## Где что лежит

| Когда | Читать |
|---|---|
| Правишь или пишешь текст темы | `docs/agents/writing-rules.md`, `docs/agents/lesson-structure.md` |
| Правишь вид: цвет, размер, отступы, вёрстку | `docs/agents/visual-decisions.md`, `docs/agents/architecture.md` («Тема и шов к библиотеке») |
| Ставишь пакет, пишешь тест, запускаешь сервер или e2e | `docs/agents/stack.md` |
| Новый слайс, виджет, демо, остров React/Vue, анимация | `docs/agents/architecture.md` |
| Берёшься за тему, которую уже правили | `docs/agents/content-fixes.md` — журнал правок содержания и найденных дефектов |

Новое правило записывается в профильный файл `docs/agents/`. Сюда, в выжимку, — только одной строкой, если его нужно помнить всегда.

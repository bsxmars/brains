# Генераторы и асинхронные итераторы

`lessons/generators` · выжимка обновлена 2026-11-11 по тексту темы.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- `function*` создаёт объект-генератор без выполнения тела. `next()` выполняет тело до следующего `yield` и возвращает `{ value, done }`.
- `yield` отдаёт значение наружу; следующий `next(x)` подставляет `x` в выражение, на котором генератор остановился. Первый `next(x)` ещё не может передать значение в `yield`.
- Генератор сохраняет локальные переменные и место остановки. Поэтому данные можно выдавать по запросу, не создавая весь набор заранее.

</details>

<details>
<summary><b>Карта</b> — как получать данные по частям</summary>

- У асинхронного итератора `next()` возвращает промис `{ value, done }`. `for await` ждёт и этот промис, и выполнение тела цикла перед следующим запросом.
- Асинхронный генератор объединяет `await` для ожидания данных и `yield` для передачи порции потребителю. Страницы API можно запрашивать последовательно по мере обработки.
- Его `next`, `return` и `throw` встают в общую очередь. У написанного вручную итератора такой очереди автоматически нет.
- Ранний выход из `for await` вызывает `return()` и ждёт закрытия. Освобождение ресурса размещают в `finally`.

</details>

<details>
<summary><b>Подвох</b> — что может и чего не может return()</summary>

- `return()` не прерывает текущий `await` внутри async-генератора: запрос ждёт в очереди.
- `Promise.race` с таймаутом перестаёт ждать результат, но не отменяет саму операцию.
- Чтобы выйти из ожидания, передают `AbortSignal` внутрь операции. Отказ ожидания даёт генератору пройти через `finally`.
- `yield` внутри `finally` может отсрочить завершение, а `throw`/`return` до первого `next` не входят в тело генератора.

</details>

<details>
<summary><b>Детали</b> — связь с генератором и компилятором</summary>

- Учебная `spawn` ждёт выданный промис и вызывает `next(result)` либо `throw(error)`. Возврат генератора завершает промис `spawn`.
- Это модель ожидания и продолжения. Нативная async-функция описана отдельными операциями `AsyncFunctionStart` и `Await`; стандарт не требует создавать JS-генератор.
- TypeScript и Babel могут использовать преобразование через генератор при сборке для старых сред. `__awaiter` и `_asyncToGenerator` — помощники такого преобразования.
- ES5-пример со `switch` показывает сохранение места остановки компилятором. Число `_a.label` и функция `_a.sent()` относятся к этому выводу, а не к синтаксису генератора.

</details>

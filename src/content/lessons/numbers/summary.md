# Числа в JS: IEEE 754, Smi и BigInt

- Number использует точность IEEE 754 binary64. Многие десятичные дроби не представимы точно, а расстояние между соседними значениями растёт вместе с их величиной.
- Безопасные целые ограничены Number.MAX_SAFE_INTEGER. BigInt подходит для точных целых вне этого диапазона, но не является универсальной точной десятичной арифметикой.
- Округление нужно выбирать по смыслу задачи, а не лечить любой результат одним epsilon. Для денег и других точных величин задайте масштаб и правила округления явно.
- NaN, Infinity и отрицательный ноль имеют особые правила сравнения и преобразования. Побитовые операции с Number используют ограниченное целочисленное представление и могут отбросить старшие биты.
- Модель точности не равна физическому размеру каждого значения в памяти V8. Преобразование текста, вычисление и форматирование результата — отдельные этапы, на которых можно потерять информацию.

# Числа в JS: IEEE 754, Smi и BigInt

`lessons/numbers` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** значения `number` подчиняются IEEE 754 binary64 (знак, порядок, мантисса). Это модель точности, а не физический размер каждого значения в V8. Для точных целых есть `BigInt`.
- **Зачем:** «странности» чисел предсказуемы по битам: десятичные дроби приближённы, целые точны лишь до `2⁵³`.
- **Как работает:**
  1. Числа — неравномерная сетка; результат сдвигается к ближайшему делению.
  2. Печать даёт самую короткую запись того же double.
  3. V8 держит малые целые в ячейке (Smi), остальное обычно — HeapNumber в куче (массив из одних дробных — без упаковки).

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- `0.1 + 0.2` — соседний с `0.3` double. Допуск выбирают по задаче: относительный зависит от масштаба, абсолютный — в её единицах. В примере координат допустимо отклонение до 0.5 CSS-пикселя включительно → «раздел 0.1 + 0.2».
- Большие id из JSON портятся молча; спасают строки или reviver → «раздел Предел целых».
- Три равенства расходятся на `-0` и `NaN` → «раздел −0 и NaN».
- `toFixed` округляет хранимое значение, `Intl` — короткую запись → «раздел Печать и округление».
- `BigInt` не смешивается с `number` в арифметике, живёт в куче → «раздел BigInt».
- Побитовые операторы режут до 32 бит → «раздел Побитовые операции».
- Пример суммы: строка `"100.00"` → `10000n` копеек → доли `3334n, 3333n, 3333n` → строки `"33.34", "33.33", "33.33"`. Остаток получают первые доли, сумма сохраняется. Ввод и форматирование обходятся без `number` → «раздел Деньги».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `Number.EPSILON` годится лишь для чисел порядка единицы.
- `BigInt(2 ** 53 + 1)` не спасает: аргумент округлился раньше.
- Строка в массиве дробных утраивает его вес в Node (в Chromium — удваивает).

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Ручной разбор `1.5 = 1.1₂ · 2⁰`: знак 0, порядок 1023, мантисса — 1 и 51 ноль. Hex, субнормальные и специальные значения — дополнительный разбор → «раздел Устройство double».
- `MAX_SAFE_INTEGER` = `2⁵³ − 1` → «раздел Предел целых».
- `(1.005).toFixed(2)` → `"1.00"` → «раздел Печать и округление».
- Smi: Node до `2³¹ − 1`, Chrome до `2³⁰ − 1` → «раздел Smi и HeapNumber».
- Байт на элемент в Node: 8 / 8 / 24 / 32 → «раздел Smi и HeapNumber».

</details>

# Цикл событий Node: фазы libuv

`lessons/node-event-loop` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** функция `uv_run` из libuv: круг из шести фаз плюс две очереди Node — `nextTick` и микрозадачи, — о которых libuv не знает.
- **Зачем:** колбэки таймеров, сети и файлов приходят по одному после того, как модуль дочитан. Ждёт цикл во сне в poll, не тратя процессор.
- **Как работает:**
  1. timers → pending → idle/prepare → poll → check (`setImmediate`) → close.
  2. После **каждого** колбэка: вся очередь `nextTick`, потом все микрозадачи — пока обе не опустеют.
  3. В poll цикл спит до ближайшего таймера или события ОС; файлы, `dns.lookup`, хеши и сжатие уходят в пул потоков.
  4. Круг идёт, пока есть хендлы с ref, запросы или закрываемые хендлы.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Таймеры стоят до круга и в его конце; часы обновляются только перед timers и после poll → «раздел Оборот uv_run».
- Рекурсивный `nextTick` морит цикл голодом, `setImmediate` — нет → «раздел Между колбэками».
- Из модуля и из check — гонка, из poll и timers — `setImmediate` первый всегда → «раздел setTimeout и setImmediate».
- Таймаут poll: 0, до ближайшего таймера или «спать до пробуждения»; бесконечная цепочка `setImmediate` не даёт уснуть → «раздел Poll».
- Одна очередь пула на файлы, DNS, хеши и сжатие; `localhost` идёт через пул, IP — нет → «раздел Пул потоков».
- `unref`, `beforeExit`, `exit`; промис процесс не держит → «раздел Выход процесса».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `nextTick` из `.then` или после `await` идёт после оставшихся микрозадач.
- `setImmediate` изнутри `setImmediate` — уже следующий круг: очередь check берётся снимком.
- Медленный `readFile` при нормальной задержке цикла — пул занят хешами; `UV_THREADPOOL_SIZE` после первой задачи пула молча игнорируется.

</details>

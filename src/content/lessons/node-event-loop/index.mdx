    Порядок колбэков в Node не загадка: libuv обходит фазы всегда одним кругом, а Node после
    каждого колбэка сливает две свои очереди. Непредсказуемо ровно одно — успела ли пройти
    миллисекунда, — и по коду видно, где это решает исход.

  прочитанные файлы приходят потом, по одному, из цикла событий. Сам цикл написан не на JS,
  а на C, в библиотеке libuv. Node добавляет к нему две очереди, о которых libuv не знает,
  и пул потоков для работы, которую операционная система не умеет делать «по готовности».

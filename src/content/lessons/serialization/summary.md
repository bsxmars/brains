# Копирование и сериализация: JSON и structuredClone

`lessons/serialization` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** копия объекта — всегда обход; потери каждого способа следуют из его шагов.
- **Зачем:** ошибки копирования тихие: дата становится строкой, вложенный массив остаётся общим, класс теряет методы.
- **Как работает:** спред — один уровень, значения без дескрипторов; JSON — всё дерево, но только шесть видов значений; `structuredClone` — дерево с типами (по слотам) и графом ссылок, без прототипов и функций.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Спред и `Object.assign` вызывают геттеры, теряют неперечисляемое и флаги → «раздел Один уровень».
- «Нет значения»: в объекте ключ пропал, в массиве `null`; общая ссылка пишется дважды, цикл — `TypeError` → «раздел JSON.stringify».
- Replacer идёт сверху вниз, reviver — снизу вверх; `undefined` из reviver удаляет свойство → «раздел JSON.parse».
- `structuredClone` сохраняет общие ссылки и циклы через таблицу `memory`; буфер можно перенести → «раздел structuredClone».
- `cloneDeep` не падает, но оставляет ссылки на оригинал и прототип без `#`-полей → «раздел Три способа».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Replacer видит дату строкой (`toJSON` раньше); оригинал — `this[key]`.
- `DataCloneError` — посреди обхода: геттеры до функции уже вызваны.
- Свой класс ошибки после `structuredClone` — просто `Error` без своих полей.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Шаги `stringify`: чтение → `toJSON` → replacer → развернуть обёртки → запись; корень с ключом `""` → «раздел JSON.stringify».
- Отступ ≤ 10; `NaN`/`Infinity` → `null`, `BigInt` → `TypeError` → «раздел JSON.stringify».
- Копия объекта — всегда `{}` с `Object.prototype`; `lastIndex` у `RegExp` → 0; `cause` копирует V8 → «раздел structuredClone».
- Тот же алгоритм: `postMessage`, IndexedDB, `history.pushState` → «раздел structuredClone».
- `9007199254740993` приезжает как `…992`, спасает `context.source`; повтор ключа — побеждает последний → «раздел JSON.parse».

</details>

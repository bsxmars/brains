# Колбэки

- Callback — функция, которую передают другому коду для последующего вызова. Кто вызывает её, тот определяет время, аргументы, число вызовов и контекст this.
- Передача callback не создаёт асинхронность. При немедленном вызове действует текущий стек, при отложенном вызывавший кадр уже может завершиться.
- Контракт должен описывать результат и канал ошибки. Throw в позднем callback не попадёт в try/catch вокруг уже завершившейся регистрации.
- Переданный метод может потерять this, а замыкание — сохранить данные дольше нужного. Привязка контекста и очистка регистрации являются отдельными обязанностями.
- Promise фиксирует один исход, но обёртка не запрещает исходному API повторно вызвать callback или продолжить работу. Для событий и потоков нужен договор о многократной доставке и отписке.

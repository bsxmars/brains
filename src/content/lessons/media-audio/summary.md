# Звук: Web Audio API

- Web Audio описывает звук графом источников, обработки и выхода. Аудиовычисления и часы AudioContext не совпадают с очередью таймеров страницы.
- `start()` и `stop()` можно планировать по currentTime. Для точного звука предпочтительнее этот договор, чем ожидание setTimeout на загруженном главном потоке.
- Политика браузера может оставить контекст приостановленным до действия пользователя. Проверяйте state и результат resume, а не только успешное создание AudioContext.
- AudioParam позволяет задавать переходы значений без резких скачков сигнала. Собственную обработку выносят в AudioWorklet с учётом ограниченного времени на блок.
- Звук требует очистки графа, источников и захвата по сроку жизни. Отдельный аудиопоток не гарантирует отсутствие сбоев при любой нагрузке или неограниченных выделениях памяти.

# Звук: Web Audio API

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** API, в котором звук собирают из узлов графа, а сэмплы считает отдельный поток браузера.
- **Зачем:** звук с точностью до сэмпла и без заиканий, даже когда главный поток занят.
- **Как работает:**
  1. `AudioContext` → источник (`OscillatorNode`, `AudioBufferSourceNode`) → `GainNode` → `destination`, `start(when)` и `stop(when)` по часам `currentTime`.
  2. До жеста пользователя контекст `suspended`; `resume()` — в обработчике клика.
  3. Параметры меняют расписанием `setValueAtTime` / `linearRampToValueAtTime`, а не присваиванием — иначе щелчок.
  4. Поток звука считает блоками по 128 сэмплов; свою обработку пишут на `AudioWorklet` с `process()`.

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `resume()` без жеста не отклоняется, а висит; WebKit даже не предупреждает в консоли.
- Контекст из обработчика клика в Firefox и WebKit ещё `suspended` — нужен `await ctx.resume()`.
- `linearRampToValueAtTime` ведёт линию от предыдущего события, без якоря — от нуля секунд.
- `exponentialRampToValueAtTime(0, …)` — `RangeError`.
- `audioWorklet` есть только в безопасном контексте.
- `decodeAudioData` отсоединяет исходный буфер (кроме WebKit).
- У Firefox нет `OfflineAudioContext.suspend`.

</details>

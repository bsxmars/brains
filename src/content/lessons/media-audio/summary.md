# Звук: Web Audio API

`lessons/media-audio` · выжимка составлена с ИИ 2026-11-03 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** API, в котором звук собирают из узлов графа, а сэмплы считает отдельный поток браузера.
- **Зачем:** планирование звука по собственным часам и обработка вне главного потока. Это не обещает отсутствие треска при любой нагрузке.
- **Как работает:**
  1. `AudioContext` → источник (`OscillatorNode`, `AudioBufferSourceNode`) → `GainNode` → `destination`, `start(when)` и `stop(when)` по часам `currentTime`.
  2. Контекст может быть suspended из-за политики запуска. Запрашивают resume в обработчике действия пользователя и учитывают state; автоматический запуск не одинаков для всех профилей.
  3. Для плавного изменения звучащего сигнала задают переход AudioParam. A-rate вычисляет значения по сэмплам, k-rate — по блокам; начальное присваивание само по себе допустимо.
  4. Размер блока по умолчанию — 128 кадров, но возможны другие размеры; свою обработку пишут на `AudioWorklet` с `process()`.

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- При заблокированном запуске resume может оставаться ожидающим. Предупреждения консоли не заменяют проверку состояния.
- На стенде контекст из обработчика клика в Firefox и WebKit ещё `suspended` — нужен `await ctx.resume()`.
- linearRampToValueAtTime задаёт конец перехода; для нужной начальной точки используют явный setValueAtTime и учитывают старое расписание.
- `exponentialRampToValueAtTime(0, …)` — `RangeError`.
- `audioWorklet` доступен в безопасном контексте. Без входного канала пример process выдаёт нули; длина блока берётся из outputs, не из константы 128.
- В пробах Chromium/Firefox decodeAudioData отсоединил исходный буфер; WebKit 26.6 сохранил его.
- На Firefox 155 нет `OfflineAudioContext.suspend`.

</details>

- В пробе с нулевым сигналом главный поток занят 300 мс, а process продолжает вызываться. Счётчик не измеряет слышимое качество → «раздел AudioWorklet».

# Процессы и потоки в Node

- Долгий синхронный расчёт задерживает event loop Node. Promise и await не создают параллельное выполнение этого расчёта.
- Worker_threads исполняет JavaScript в другом потоке того же процесса с отдельными JS-кучей и глобальными переменными. Child_process запускает отдельную программу с собственным адресным пространством.
- Fork создаёт другой Node с каналом IPC, а не снимок текущей JS-кучи. Cluster помогает нескольким таким процессам обслуживать серверный порт, не разделяя обычное состояние приложения.
- Место выполнения и обмен данными выбираются отдельно. Клонирование, передача владения буфером и общая память имеют разные цены и требования к синхронизации.
- Пул работников должен ограничивать число задач, очередь и срок ожидания. Ошибка, сообщение с результатом, отмена и выход работника — разные события протокола, которые нужно согласовать.

<Section variant="intro" eyebrow="Один процесс — не один поток" gap={24}>
  <Callout size={19} pad="24px 26px">

    Процессы не видят память друг друга. Воркеры живут в одном процессе, но у каждого своя
    куча, и общих объектов у них нет. Поэтому в любом канале — между потоками или между
    процессами — данные копируются, и часть их при этом может потеряться без ошибки.

  </Callout>

  Сервер на Node выполняет ваш JS в одном потоке. Пока один запрос считает, остальные ждут.
  Чтобы задействовать другие ядра, у Node есть три механизма, и каждый отвечает на свой
  вопрос: где выполнить долгий расчёт, как запустить чужую программу и как раздать
  соединения одного порта по ядрам.

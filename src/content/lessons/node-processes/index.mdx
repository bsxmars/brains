  Обычный `await` этот расчёт в другой поток не переносит. Чтобы выполнять JS параллельно,
  запускают воркер или другой процесс; асинхронный ввод-вывод сам по себе такой замены не требует.

  ### Буфер, который отдавать нельзя: `markAsUntransferable`

  Обычный `ArrayBuffer` можно передать воркеру, отсоединив память у отправителя.
  Маленькие Node-буферы могут ссылаться на общий пул: его отсоединять нельзя,
  поэтому Node помечает такой буфер как непереносимый.

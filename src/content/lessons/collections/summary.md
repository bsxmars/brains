# Коллекции: Map, Set и словари

- Обычный объект хранит свойства со строковыми и символьными ключами, а чтение может идти в прототип. Object.create(null) убирает прототип, но не меняет правила преобразования ключей.
- Map хранит ключи любого типа отдельно от свойств объекта. Объектный ключ определяется идентичностью ссылки, а не равенством текущих полей.
- `get` возвращает значение, `has` проверяет наличие. Сохранённое undefined нельзя отличить от отсутствующего ключа одним результатом get.
- Set хранит уникальные значения по SameValueZero: NaN совпадает с NaN, а нули разных знаков считаются одним значением. Разные объекты не становятся одинаковыми из-за похожего содержимого.
- Выбирайте коллекцию по операциям и сроку жизни ключей. Map и Set удерживают записи сильными ссылками; слабые коллекции не являются обычным перечисляемым кешем с известным размером.

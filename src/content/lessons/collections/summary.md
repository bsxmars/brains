# Коллекции: Map, Set и словари

`lessons/collections` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** `Map` и `Set` — хеш-таблицы, которые помнят порядок вставки; объект — запись, `Map` — словарь.
- **Зачем:** объект-словарь портит ключи из данных: приводит к строке, «находит» имена из `Object.prototype`, ставит целые числа вперёд.
- **Как работает:** записи дописываются в конец массива; хеш ведёт в корзину; удаление оставляет дырку; итератор идёт по живой таблице, а не по копии.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Словарь без прототипа лечит только «чужие имена», и у него свои цены → «раздел Объект-словарь».
- Ключи сравниваются по SameValueZero: объект — по ссылке, `NaN` равен себе, нули не различаются → «раздел Map».
- «Достать или положить» одной строкой и мост в объект/JSON, где ключи снова строки → «раздел Map».
- У `Set` есть операции над множествами; аргумент — объект «как множество» → «раздел Set».
- Изменения на ходу: удалённое не придёт, добавленное придёт, перевставленное — ещё раз → «раздел Обход».
- Слабые коллекции не мешают GC, но не перечисляются → «раздел Слабые».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `m[key] = v` пишет свойство, а не запись; `JSON.stringify(m)` и `{...m}` дают пустой объект.
- `delete` + `set` текущего ключа в `for…of` — вечный цикл; обходить `[...m]`.
- `forEach` даёт `(value, key)`, `for…of` — `[key, value]`.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- `Object.create(null)`: `String(dict)` бросает `TypeError`, вместо `hasOwnProperty` — `Object.hasOwn` → «раздел Объект-словарь».
- `getOrInsert` создаёт значение всегда, `getOrInsertComputed` — только для нового ключа → «раздел Map».
- `union`, `intersection`, `difference`, `symmetricDifference`, `isSubsetOf`, `isDisjointFrom`; `union([2])` — `TypeError` про `size` → «раздел Set».
- V8: `OrderedHashMap`/`OrderedHashSet`, хеш объекта — случайное число в самом объекте → «раздел Изнутри».
- Ключ `WeakMap` — объект или `Symbol()`, не строка и не `Symbol.for` → «раздел Слабые».
- `Object.groupBy` — результат без прототипа, `1` и `'1'` склеиваются; `Map.groupBy` — ключи-объекты → «раздел Что выбрать».

</details>

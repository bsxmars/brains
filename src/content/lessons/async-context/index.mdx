<Section variant="intro" eyebrow="Чей это запрос" gap={24}>
  <Callout size={19} pad="24px 26px">

    Глобальная переменная хранит одно текущее значение на всех. Асинхронный контекст позволяет
    каждой цепочке работы видеть своё значение, даже когда запросы выполняются вперемежку.
    В Node `AsyncLocalStorage` сохраняет его для продолжений `await`, обработчиков `then`
    и таймеров. Произвольный синхронный вызов колбэка сам этого не делает.

  </Callout>

  Сервер обрабатывает много запросов сразу, и у каждого свой id — для логов, трассировки,
  прав доступа. Протаскивать его параметром через контроллер, сервис, репозиторий и логгер
  можно. Но каждый промежуточный слой тогда тоже должен принимать и передавать этот параметр. Хочется прочитать «текущий
  запрос» откуда угодно, как глобальную переменную. Только обычная глобальная переменная
  для этого не годится, и причина — в `await`.

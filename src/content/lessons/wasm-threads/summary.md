# WebAssembly: память, потоки и граница с JS

- WebAssembly.Module содержит подготовленный код, а Instance связывает его с импортами и предоставляет экспорты. Один модуль можно использовать для нескольких экземпляров.
- На границе с JavaScript действуют конкретные типы: i32 — 32-битное целое, поэтому преобразование Number может потерять дробную часть или старшие биты.
- Линейная память хранит байты. Для строки часто передают адрес и длину после кодирования; правила кодировки и владения памятью должны совпадать с модулем.
- Рост памяти влияет на доступные виды memory.buffer. Не используйте старые предположения о буфере после grow; общая и обычная память имеют разные правила.
- Параллельный расчёт организуют Worker или worker_threads с нужными экземплярами и общей памятью. Сам вызов Wasm остаётся синхронной работой текущего потока, а синхронизация общих данных требует атомарных операций.
- Wasm полезен для подходящего вычислительного ядра и повторного использования кода. Полная цена включает загрузку, компиляцию, подготовку данных и обмен через границу, а не только время одной функции.

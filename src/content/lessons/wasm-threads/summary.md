# WebAssembly: память, потоки и граница с JS

`lessons/wasm-threads` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** модуль Wasm знает только числа, ссылки и линейную память — один массив байтов.
- **Зачем:** запускать чужой код на C, C++, Rust в браузере; почти все ошибки — на границе с JS.
- **Как работает:** модуль без состояния + импорты → экземпляр со своей или импортированной памятью; строка — адрес и длина, с копией туда и обратно; поток — воркер со своим экземпляром на общей импортированной памяти; синхронизация — атомарные инструкции, те же, что `Atomics`.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Строгий порядок секций даёт потоковую компиляцию; импорты проверяются при создании экземпляра → «раздел Модуль и экземпляр».
- Таблица держит ссылки на функции вне памяти → «раздел Модуль и экземпляр».
- Рост памяти отсоединяет буфер; выход — растягиваемый буфер → «раздел Линейная память».
- Числа на границе приводятся без проверки; строку можно передать ссылкой (JS String Builtins) → «раздел Граница с JS».
- Без изоляции общая память создаётся, но в воркер не уходит → «раздел Общая память и потоки».
- `v128` не пересекает границу → «раздел SIMD и инструменты».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Вид на память, заведённый до роста, молча пустеет; растит её распределитель внутри вызова — пересоздавать вид после каждого вызова.
- Готовность к потокам — по `crossOriginIsolated`, не по `typeof SharedArrayBuffer`.
- Ловушка не откатывает записанное; в браузере главный поток не может ждать.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Страница 64 КиБ; `grow` возвращает прежний размер; изнутри за пределом — `-1` → «раздел Линейная память».
- `toResizableBuffer()` требует `maximum` → «раздел Линейная память»; `shared: true` — тоже → «раздел Общая память и потоки».
- `i32(2 ** 32 + 5)` → 5; `i64(5)` → `TypeError`, нужен `BigInt` → «раздел Граница с JS».
- `bump` — ровно 2 000 000, `racy` — около миллиона → «раздел Общая память и потоки».

</details>

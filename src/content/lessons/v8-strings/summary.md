# Строки в V8

`lessons/v8-strings` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** строка в V8 — узел дерева; настоящие буферы есть только в листьях.
- **Зачем:** строки неизменяемы, поэтому склейка и срез идут за O(1) без копии, а имена свойств сравниваются по адресу. Главная плата: короткая строка может держать огромный буфер; вторая — копирование, отложенное до первого чтения.
- **Как работает:** склейка — узел `ConsString`; срез от порога — окно `SlicedString`; первое чтение символа расплющивает дерево; ключ свойства интернируется — объект на месте становится `ThinString`.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Представление по самой строке не видно — только под флагом V8; снимок кучи различает склейку и срез → «раздел Что видно».
- Интернированные строки `===` сравнивает по адресу, остальные — посимвольно, если длины равны → «раздел Таблица строк».
- Пять представлений, включая внешнюю; `repeat` тоже даёт дерево → «раздел Представления».
- Квадратичность — от чередования склейки и чтения, а не от `+=` → «раздел Flatten».
- Половина «способов скопировать» родителя не отпускает: возвращает тот же срез → «раздел Копия».
- Длина, точки, графемы, байты — разные числа; одна буква выше latin-1 удваивает всю строку → «раздел Юникод».
- ReDoS, устаревший совет «+= квадратичен, бери join» → «раздел Тонкости».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Срез из ответа на 50 МБ в кеше держит все 50 МБ; `normalize()`, `String()`, `slice()` копию не делают.
- Пауза на безобидном `indexOf` — оплата отложенного расплющивания.
- Обрезка по `.length` рвёт эмодзи; резать по графемам.

</details>

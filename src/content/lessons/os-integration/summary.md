# Страница и система: экран, „Поделиться“, значок, оплата

- Системные Web API просят браузер и ОС выполнить действие: поделиться данными, удержать экран, показать badge или открыть платёжный интерфейс. Это запрос возможности, а не безусловная команда.
- Проверяйте наличие API и условия доступа: безопасный контекст, права, состояние документа и политику встраивания. У каждого API свой набор требований.
- Активацию пользователя нужно использовать в нужный момент. Отложенный вызов после произвольной асинхронной работы может потерять необходимое право, а срок активации не универсален.
- Успех запроса не означает бесконечное владение ресурсом: wake lock может быть отозван, интерфейс закрыт пользователем, а возможность не поддержана устройством.
- Обрабатывайте отказ и предоставляйте понятный запасной путь. Платёжное окно не заменяет серверную проверку и фиксацию оплаты, а badge не является надёжным хранилищем числа событий.

# Замыкания и области видимости

`lessons/closures` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** замыкание — любая функция вместе со ссылкой `[[Environment]]` на окружение, где её создали.
- **Зачем:** функция видит переменные места, где её написали, даже после возврата того вызова; отсюда счётчики и приватность.
- **Как работает:** окружение — таблица имён плюс ссылка `outer`; поиск имени идёт по цепочке наружу; при вызове новое окружение берёт `outer` из `[[Environment]]` функции, а не у вызывающего; окружение живёт, пока до него можно дойти.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Виды окружений; глобальное — из двух частей → «раздел Окружения».
- Поднимаются все объявления, разница — с каким значением; мёртвая зона `let`/`const` — время, а не место; `typeof` безопасен только для несуществующего имени → «раздел Подъём и TDZ».
- Каждый вызов даёт новое окружение, соседние функции делят одно → «раздел Замыкание».
- `for (let …)` копирует значение в окружение каждой итерации; до `let` то же делали IIFE → «раздел Цикл for».
- V8 кладёт в Context только захваченные переменные, но Context один на вызов; `eval` тащит туда всё; отладчик не видит незахваченное → «раздел Что держит V8».
- Приватность через замыкание против `#`-полей → «раздел Приватность».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Безобидный колбэк держит тяжёлый объект, если его захватила соседняя функция того же вызова.
- `let` в цикле копирует значение, а не номер итерации: изменение `i` в теле уходит в следующую итерацию; замыкание в части `init` видит только первую копию.
- Повторный глобальный `let` в другом `<script>` — `SyntaxError`, скрипт не выполняется целиком.

</details>

<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Фабрика: методы разные у каждого объекта; `#`-поле: методы в прототипе, проверка `#count in obj` → «раздел Приватность».

# Общая память и Atomics

`lessons/atomics` · выжимка составлена с ИИ 2026-11-03 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** операции над общим буфером, которые неделимы и задают порядок между потоками.
- **Зачем:** без них прибавки из разных потоков теряются, а флажок «готово» бывает виден раньше данных.
- **Как работает:**
  1. Одно число — атомарной операцией: `Atomics.add`, `compareExchange`.
  2. Пачку данных — обычными записями, а флажок — `Atomics.store`; читатель проверяет его `Atomics.load` и видит все данные.
  3. Ждать — `Atomics.wait` и `notify`; на главном потоке браузера — только `waitAsync`.
  4. Несколько полей сразу — под замком из `compareExchange` и `wait`.

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `Atomics.wait` на главном потоке браузера — `TypeError`; в Node разрешён, и код ломается при переносе.
- Флажок без `Atomics`: на x86 работает всегда, на ARM ломается раз на миллион.
- Дробных атомарных операций нет; `BigInt64Array` хочет `1n`.
- Спин-цикл занимает ядро целиком.

</details>

# Плеер вне вкладки: Picture-in-Picture, Media Session и захват экрана

`lessons/media-outside` · выжимка по актуальному тексту темы, 2026-11-11.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** способы остаться с человеком, который ушёл из вкладки, — окно поверх программ, кнопки в системе, показ экрана.
- **Зачем:** видео в углу экрана при работе в другой программе, пауза с наушников, демонстрация экрана в звонке.
- **Как работает:**
  1. `video.requestPictureInPicture()` — кадр видео в окне поверх всего; одно окно на документ.
  2. `documentPictureInPicture.requestWindow()` — окно с целым документом; элемент туда переезжает, стили переносят сами.
  3. `navigator.mediaSession` — метаданные, обработчики кнопок, `setPositionState`.
  4. `getDisplayMedia()` — человек выбирает экран, окно или вкладку; ответ — `MediaStream`.
  5. Запуск защищённых API связывают с действием пользователя. Срок активации определяет браузер; около 5 с — результат стенда, а не переносимый таймер. Открытие окна может потреблять активацию.

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `await fetch` перед открытием окна — `NotAllowedError`, если ответ шёл дольше ~5 с.
- `page.evaluate` в Playwright выдаёт странице активацию: тест «без клика» врёт.
- `track.stop()` не присылает `ended`. Очистку вызывают и из обработчика ended, и непосредственно при остановке кодом; останавливают также аудио и снимают srcObject.
- Stop во время выбора источника не может отменить само окно выбора, но поздний поток нужно остановить и не подключать к превью.
- Ранний timeupdate может прийти при duration=NaN: setPositionState вызывают только с подходящими данными или сбрасывают позицию без аргумента.
- Любой `await` между `getDisplayMedia` и `setFocusBehavior` — `InvalidStateError`.
- Неизвестное действие медиасессии — `TypeError`, и список действий в движках разный.
- `cssRules` таблицы с чужого источника — `SecurityError`.

</details>

<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Удалили видео из DOM: Chromium окно оставляет, Firefox закрывает → «раздел Картинка в картинке».

- `duration: Infinity` принимает только Chromium → «раздел Media Session».
- В пробах стенда Firefox и WebKit не дали аудиодорожку захвата; фиктивный звук Chromium не проверяет реальную передачу системного звука → «раздел Захват экрана».

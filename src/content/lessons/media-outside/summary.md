# Плеер вне вкладки: Picture-in-Picture, Media Session и захват экрана

- Picture-in-Picture, Media Session и захват экрана решают разные задачи: отдельное окно, системное управление воспроизведением и получение дорожек выбранного источника.
- Для защищённых действий проверяйте поддержку, состояние документа и необходимую активацию пользователя. Вызов после произвольного ожидания может уже не иметь нужного разрешения.
- Видео-PiP показывает видео, Document PiP предоставляет отдельный документ со своими условиями переноса узлов и стилей. Не считайте эти API одинаковыми способами открыть popup.
- Media Session передаёт метаданные и обработчики системных действий, но не воспроизводит и не сохраняет медиа самостоятельно. Состояние нужно согласовывать с реальным проигрывателем.
- `getDisplayMedia()` просит человека выбрать источник; захват может завершиться извне. Останавливайте свои дорожки, очищайте обработчики и сохраняйте рабочий сценарий при отказе пользователя или отсутствии API.

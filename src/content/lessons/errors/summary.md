# Ошибки и стеки

`lessons/errors` · выжимка обновлена 2026-11-11 по тексту темы.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- Ошибка — объект с именем, сообщением, стеком и возможной причиной `cause`. У обычного `Error` нужные поля не попадают в `JSON.stringify`: они неперечисляемые или находятся в прототипе.
- Внутренний слой добавляет контекст через `new Error(message, { cause })`; граница приложения показывает сообщение и отправляет один отчёт с явно перечисленными полями.
- В V8 кадры снимаются при создании ошибки, а строка `stack` формируется позже. Повторный `throw` того же объекта не снимает новый стек.

</details>

<details>
<summary><b>Карта</b> — как не потерять ошибку</summary>

- Проверяйте `res.ok`: HTTP 404 и 500 сами по себе не отклоняют промис `fetch`.
- Ловите ошибку там, где можете восстановиться, показать состояние или отправить отчёт. Пустой catch и один console.log скрывают сбой от мониторинга.
- При ожидаемом отказе обработайте только известный случай, остальные ошибки пробросьте дальше.
- Не заменяйте исходную ошибку строкой. `cause` сохраняет первопричину вместе с контекстом операции.
- У промиса должен быть владелец, который дождётся отказа. У ошибки должен быть один отчёт, а не отдельный на каждом уровне.

</details>

<details>
<summary><b>Подвох</b> — крайние случаи</summary>

- `finally` может заменить и возвращаемое значение, и исходное исключение. `using` сохраняет обе ошибки в `SuppressedError`.
- Глобальный обработчик — последний путь диагностики. Браузер сообщает событием, а Node по умолчанию печатает ошибку и завершает процесс.
- Скрипт с другого источника без подходящих CORS-настроек может дать только Script error. без объекта ошибки.
- `captureStackTrace`, `stackTraceLimit` и `prepareStackTrace` — отдельные инструменты V8, их подробности приведены дополнительно.

</details>

<details>
<summary><b>Детали</b> — что увидит диагностика</summary>

- Асинхронный стек V8 восстанавливается по поддерживаемым связям `await` и комбинаторов. Обычный колбэк или связь через `.then` в стеке могут отсутствовать.
- `StackLab` показывает заранее снятые стеки Node и Chromium; `ReportLab` исполняет выбранный пример в браузере и собирает отчёт полной функцией из темы.
- Отчёт сохраняет цепочку причин, простые дополнительные поля и ограниченный стек. Нужны защита от циклов, предел глубины и обработка `AggregateError`/`SuppressedError`.
- Парсер из темы понимает только формат кадров V8. В приложении разбор разных форматов обычно поручают SDK мониторинга; координаты собранного кода переводят картами исходников.

</details>

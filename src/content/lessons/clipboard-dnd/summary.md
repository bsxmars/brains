# Буфер обмена и перетаскивание

`lessons/clipboard-dnd` · выжимка составлена с ИИ 2026-11-03 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** два входа к одному механизму — данные лежат в `DataTransfer` парами «тип → данные», браузер решает, кому их показать.
- **Зачем правила:** буфер общий для всей системы, в нём пароли и коды; страница не должна ни подменять, ни подглядывать.
- **Как работает:**
  1. `writeText` — по жесту пользователя и при фокусе документа; `readText` — с разрешения. Отказ — `NotAllowedError`.
  2. В `copy` своё кладут `setData` **и** `preventDefault`; в `paste` читают `clipboardData`, картинка приходит файлом.
  3. Несколько видов сразу — `ClipboardItem`; HTML из `read()` уже почищен, но чистить всё равно самим.
  4. Перетаскивание: `dragstart` кладёт, `dragover` с `preventDefault` разрешает бросить, `drop` читает.
  5. В `dragover` видно только `types`; после события `DataTransfer` пуст — всё забирать в обработчике.

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `writeText` из консоли DevTools — «Document is not focused».
- `setData` в `copy` без `preventDefault` пропадает молча.
- Нет `preventDefault` в `dragover` — `drop` не придёт.
- Firefox отдаёт данные в `dragover`, Chromium — нет; синтетический `DragEvent` защиты не знает.
- Папка в `files` — `File` без типа, `text()` — `NotFoundError`.
- Файл мимо зоны браузер открывает сам.
- С клавиатуры перетащить нельзя — нужен второй путь.

</details>

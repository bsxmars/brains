# Event Loop

- Цикл событий связывает события браузера с выполнением JavaScript. Пока главный поток занят текущим синхронным кодом, ввод и другая работа этого потока ждут.
- Задачи приходят из разных источников. Порядок внутри источника и выбор между источниками — разные правила; одной общей очереди «всего браузера» недостаточно для объяснения порядка.
- В checkpoint микрозадачи выполняются до опустошения, включая добавленные по ходу. Сюда относятся реакции Promise и продолжения await; они не становятся отдельной возможностью нарисовать кадр.
- Таймер задаёт момент, раньше которого callback не готов к запуску, а не обещанное время выполнения. RequestAnimationFrame связан с обновлением изображения и работает по другим правилам.
- Бесконечная цепочка микрозадач может задержать события и кадры. Для уступки браузеру нужен подходящий переход к другой задаче; даже пустой стек не означает автоматически следующий кадр.
- Воркеры имеют собственное выполнение, а связанные окна могут разделять цикл. Цикл, физический поток и процесс — разные единицы; правила Node нужно рассматривать отдельно.

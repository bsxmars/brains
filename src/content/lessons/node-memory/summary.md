# Память в Node

- RSS описывает резидентные страницы процесса, а показатели JS-кучи относятся к изоляту. При worker_threads нужно понимать, какая область измерена каждым счётчиком.
- HeapUsed включает ещё не собранный мусор. ArrayBuffers входит в external, поэтому эти показатели нельзя безусловно складывать как независимые виды памяти.
- Buffer и другие внешние данные могут занимать много памяти при небольшом росте JS-кучи. Снимок помогает найти владельца, но не заменяет картину всего процесса.
- Рост после сопоставимых циклов нагрузки и GC — основание исследовать удержание, а не готовый диагноз. Фрагментация, нативные ресурсы и кеши требуют других проверок.
- Лимит V8 и лимит контейнера ограничивают разное. Оставляйте запас для буферов, потоков, нативной работы и диагностики; отсутствие OutOfMemoryError в JS не гарантирует, что ОС не остановит процесс.

# MessageChannel

`lessons/message-channel` · выжимка обновлена 2026-11-11 по тексту темы.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- Канал создаёт пару связанных портов. `port1.postMessage(value)` отправляет сообщение получателю на `port2`, ответ идёт обратно тем же способом.
- Один порт можно передать воркеру или iframe через существующий `postMessage` и transfer-список. Связь с парным портом сохраняется, а прежний владелец больше не может использовать переданный объект.
- `onmessage` запускает порт браузера автоматически. С `addEventListener` нужен отдельный `start()`: до запуска сообщения ждут в очереди.
- Когда обмен закончен, канал закрывают через `close()`. Отправка после закрытия не обязана сообщать об ошибке.

</details>

<details>
<summary><b>Карта</b> — когда это полезно</summary>

- Канал с iframe: при передаче порта проверяют адресата и источник; дальше обмен идёт только между владельцами портов.
- Один воркер может обслуживать несколько независимых портов с отдельными обработчиками.
- У `SharedWorker` порт — основной интерфейс связи со вкладкой.
- Для запроса-ответа можно создавать одноразовый порт. Ответ и таймаут должны закрывать его; завершение другой стороны само по себе не гарантирует ответа.
- В браузере сообщения порта выполняются отдельными задачами. На них можно разбивать длинную работу; обработка ввода и кадр между любыми двумя задачами не гарантированы.

</details>

<details>
<summary><b>Подвох</b> — частые причины ошибок</summary>

- `MessagePort` передаётся только через transfer-список. `ArrayBuffer` без этого списка копируется.
- В transfer-списке указывают `view.buffer`, а не сам TypedArray. Все виды на переданный буфер у отправителя теряют доступ к его памяти.
- Буфер, помещённый в transfer-список, но не в сообщение, отсоединится у отправителя, а получатель к нему не доберётся.
- Открытый слушающий порт может удерживать обработчик и данные из его замыкания. Очистку выполняют при успехе, ошибке, отмене и удалении компонента.
- Состояния в схеме жизненного цикла вычисляет учебная модель. Примеры transfer-списка выполняет сам браузер.

</details>

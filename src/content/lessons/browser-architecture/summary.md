# Устройство браузера

- Вкладка, документ, агент, поток и процесс — разные единицы. Их нельзя посчитать друг из друга по правилу «одна вкладка — один процесс».
- Origin определяет обычный доступ к данным, site участвует в политике размещения. Разделение по процессам усиливает изоляцию, но не заменяет веб-проверки доступа и фильтрацию ответов.
- Browser управляет навигациями и полномочиями, Renderer выполняет страницу, отдельные сервисы занимаются сетью и графикой. Разрешённые каналы IPC связывают эти части.
- Загрузка ответа и принятие нового документа — разные этапы. Пока переход ожидается, прежний Document может работать; commit не означает окончания загрузки или появления первого кадра.
- Главный поток страницы выполняет JS и значительную часть подготовки изображения. Worker может убрать расчёт с этого потока, но не выполняет DOM-layout вместо страницы.
- Для диагностики сопоставляйте Network, профиль выполнения, снимки памяти и PID. Размер JS-кучи не равен памяти процесса, а crossOriginIsolated и hardwareConcurrency не раскрывают схему процессов.

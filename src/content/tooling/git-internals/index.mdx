<Section variant="intro" eyebrow="Хранилище по содержимому" gap={24}>
  <Callout size={19} pad="24px 26px">

    Git — это хранилище, где ключ записи вычисляется из её содержимого. Файл, папка и коммит —
    записи такого хранилища, и ни одну из них нельзя изменить: изменённая запись получает
    другой ключ. Меняются только **ссылки** — крошечные файлы, где записано, какой коммит
    сейчас считается вершиной ветки.

  </Callout>

  Команды git выглядят как операции над файлами: «закоммитить», «слить», «перенести ветку».
  Внутри почти все они делают одно и то же. Пишут несколько новых объектов, если их ещё нет,
  и переписывают одну-две ссылки. Поняв эти две операции, можно предсказать, что сделает
  любая команда, и вернуть то, что кажется потерянным.

# HMR изнутри

`tooling/hmr` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** замена одного модуля в живой странице — договор сервера, клиента Vite и модулей через `import.meta.hot`.
- **Зачем:** сохранить память страницы вместо `location.reload()`; браузер модуль по адресу не забывает до конца страницы.
- **Как работает:** сервер по графу идёт от изменённого модуля по импортёрам до границы (`accept`); шлёт по WebSocket `update` или `full-reload`; клиент зовёт `dispose` старого и импортирует модуль по новому адресу с `?t=`, затем колбэк `accept`.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Граф знает только сервер; старый экземпляр модуля продолжает жить у импортёров → «раздел Граф и метка в адресе».
- Один тупик на любой ветке — перезагрузка всей страницы → «раздел Поиск границы».
- Три формы `accept`, перенос состояния через `dispose`/`data`, отказ через `invalidate`; `accept` ищется в тексте модуля → «раздел accept, dispose, invalidate».
- CSS и `.vue` `accept` дописывает инструмент; CSS-модуль себя не принимает; шаблон Vue — `rerender`, скрипт — `reload` → «раздел CSS и Vue».
- Fast Refresh — `accept` на себя плюс проверка экспортов; в сборке HMR-код вырезается → «раздел React и сборка».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `const hot = import.meta.hot; hot.accept()` сервер не видит — перезагрузка без предупреждения.
- Принять себя — значит исполниться заново: модульное состояние обнулится без `hot.data`; `accept('./dep')` не делает модуль границей для себя.
- Голый `import.meta.hot.accept()` без охраны в сборке становится `(void 0).accept()` → `TypeError`.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- `path` — чей колбэк звать, `acceptedPath` — что импортировать заново; тупик — `path: "*"` → «раздел Поиск границы».
- Клики `v1:3` → `v2:0` без переноса, `v2:3` с `hot.data` → «раздел accept, dispose, invalidate».
- `invalidate` шлёт от клиента `vite:invalidate`, второе `update` с `firstInvalidatedBy` → «раздел accept, dispose, invalidate».
- `_rerender_only`, событие `file-changed`; преамбула `$RefreshReg$`/`$RefreshSig$` → «разделы CSS и Vue», «React и сборка».

</details>

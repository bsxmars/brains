# HMR изнутри

- HMR заменяет изменённый модуль в работающей странице и пытается сохранить подходящее состояние. Это договор сборочного сервера, клиентского runtime и модулей.
- Сервер идёт по графу импортёров до границы, которая умеет принять обновление. Если подходящей границы нет, может потребоваться полная перезагрузка.
- Новый экземпляр модуля исполняется заново. Старое состояние сохраняется только предусмотренным способом, например через hot.data; dispose освобождает ресурсы прежнего экземпляра.
- Изменение экспорта и изменение реализации — разные риски. Принимающая сторона должна заново связать нужные зависимости и понимать, какие значения остались старыми.
- HMR предназначен для разработки и не доказывает корректность холодного старта. Проверяйте обычную загрузку и очищайте обработчики, таймеры и внешние подключения между заменами.

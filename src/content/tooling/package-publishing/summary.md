# Публикация npm-пакета

`tooling/package-publishing` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** `package.json` как договор: `exports` решает, какой файл получит каждый импорт, `files` — что уедет в архив.
- **Зачем:** код может быть верным, а пакет сломанным — не тот файл для `require`, типы от другого формата, нет `dist`. Видит это не автор, а пользователь в другой среде.
- **Как работает:** спецификатор делится на имя и подпуть; ищется точный ключ, потом шаблон с `*` (побеждает длинный префикс); условия перебираются сверху вниз до первого включённого, `default` включён всегда; неназванное и `null` закрыты.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Каждая среда включает свой набор условий; Node из совпавшего условия не возвращается, TypeScript — возвращается → «раздел Условия».
- Формат по расширению и `type`; `require` в Node 24 грузит ESM без `await` наверху; двойной пакет даёт два экземпляра состояния → «раздел ESM и CJS».
- `types` первым; `.d.mts`/`.d.cts` для двух форматов; маскарад типов ловит attw → «раздел Типы».
- `files` — белый список; `.npmignore` заменяет `.gitignore` целиком → «раздел Тарбол».
- Правка карты и условий — тоже API; появление `exports` — мажор → «раздел Что ломает версию».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `default` не последним делает всё ниже недостижимым — ошибки нет, файл не тот.
- `.env` npm сам не выбрасывает: без `files` секрет уезжает в архив.
- Смешанная карта (подпути + условия) падает только в Node; TypeScript и publint молчат — проверять реальным `import` и `require`.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Ошибки: `ERR_PACKAGE_PATH_NOT_EXPORTED`, `ERR_INVALID_PACKAGE_TARGET`, `ERR_INVALID_PACKAGE_CONFIG`; шаблон + `.js` → `card.js.js` → «раздел Поле exports».
- Node: `node`, `import`/`require`, `module-sync`; TS `bundler` — без `node` → «раздел Условия».
- `ERR_REQUIRE_ASYNC_MODULE`; `require(esm)` без флага с 20.19 и 22.12 → «раздел ESM и CJS».
- attw: `FalseCJS`, `FalseESM`, `FallbackCondition`, `CJSResolvesToESM` → «раздел Типы».
- `npm pack --dry-run`; всегда в архиве `package.json`, `README`, `LICENSE` → «раздел Тарбол».

</details>

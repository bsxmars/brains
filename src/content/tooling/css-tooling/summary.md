# CSS-инструменты

- CSS-инструменты преобразуют исходники до браузера: разбирают синтаксис, запускают плагины, генерируют правила и понижают возможности под выбранные targets.
- Порядок преобразований важен: следующий шаг получает результат предыдущего. Настройка браузерных целей влияет на то, какой синтаксис и префиксы останутся в выходном CSS.
- CSS Modules и scoped-стили ограничивают совпадение селекторов через переименование или атрибуты. Они не создают отдельную модель каскада и не равны Shadow DOM.
- Генератор утилит должен обнаружить нужные классы в исходниках. Строка, собираемая только во время выполнения, может не попасть в статический набор правил.
- Проверяйте итоговый CSS в браузере: корректный разбор исходника не гарантирует нужный каскад, поддержку свойства или размер результата. Source maps помогают связать преобразованное правило с источником.

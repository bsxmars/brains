    CSS-инструменты не «улучшают» стили. Они **переписывают текст** по правилам, которые
    можно повторить руками: разобрать в дерево, заменить узел, дописать запасную строку,
    переименовать класс, выписать слова из файлов. Когда результат удивляет, причина почти
    всегда в одном из этих правил.

  пользователя может не знать вложенности, а `.button` есть в каждой второй библиотеке.
  Поэтому между файлом и браузером стоят программы: PostCSS с плагинами, lightningcss,

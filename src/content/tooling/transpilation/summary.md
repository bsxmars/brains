# Транспиляция и полифилы

- Транспиляция заменяет неподдерживаемый синтаксис, а полифил предоставляет отсутствующий API. Преобразованный optional chaining не добавляет Array.prototype.at.
- Список целевых сред определяет нужные преобразования. Одна старая поддерживаемая среда может заставить изменить код для всей общей сборки.
- Понижение синтаксиса должно сохранять поведение, а не только позволять разобрать файл. Async-функции, генераторы, классы и приватные поля могут требовать helpers или runtime.
- Синтаксис, глобальные объекты и методы встроенных прототипов проверяются отдельно. Наличие Promise не означает наличие всех его новых методов.
- Контролируйте результат на реальных targets: размер, порядок подключения полифилов и влияние на глобальное окружение. TypeScript без проверки runtime API тоже не обеспечивает совместимость браузера.

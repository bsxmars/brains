# Монорепозиторий

`tooling/monorepo` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** один git-репозиторий с несколькими пакетами; история, lock-файл и CI общие.
- **Зачем:** соседи видны без публикации, а инструмент задач по графу решает порядок сборки, что пересобрать и что взять из кеша.
- **Как работает:** менеджер ставит соседа симлинком в `node_modules`; граф пакетов даёт топологический порядок по уровням; фильтр берёт изменённые пакеты плюс их зависимых; кеш задач хранит результат под хешем всех входов.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- npm кладёт ссылки на всех соседей в корень, pnpm — только объявившему; `workspace:` защищает от похода в реестр и при публикации заменяется версией → «раздел Воркспейсы».
- Фантом в монорепо приходит от соседнего пакета → «раздел Фантомы и копии».
- npm гоняет скрипты по списку воркспейсов, pnpm `-r` — по графу; уровень pnpm — барьер → «раздел Граф и порядок».
- Многоточие в фильтре — с той стороны, куда расширять; файлы корня приписываются корневому проекту → «раздел Только изменённое».
- Отравленный кеш — верная работа по неверному ключу → «раздел Кеш задач».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Второй `npm run build --workspaces` зелёный из-за старых `dist` — проверять с чистого клона.
- Переменная окружения, не названная в конфиге, в ключ не входит: прод получает стейджинговый бандл; очистка кеша не лечит.
- `[origin/main]` сравнивает с концом базы, а не с точкой ответвления; не видит неотслеживаемые файлы и правки lock-файла.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- npm 11 на `workspace:*` — `EUNSUPPORTEDPROTOCOL`; `workspace:^` → `^1.0.0`, `*` → `1.0.0` → «раздел Воркспейсы».
- Уровни фикстуры: `[utils]`, `[api, ui]`, `[admin, web]` → «раздел Граф и порядок».
- `--filter "...[origin/main]"`, `"...^@shop/ui"`; неглубокий клон без базы → «раздел Только изменённое».
- Turborepo 2: `envMode: strict`, `env`/`globalEnv`; Nx: `{ "env": "API_URL" }` в `inputs` → «раздел Кеш задач».
- Цикл в графе pnpm 11 молча запускает параллельно → «раздел Тонкие места».

</details>

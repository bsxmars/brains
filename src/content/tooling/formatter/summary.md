# Форматтер изнутри

`tooling/formatter` · выжимка составлена с ИИ 2026-11-13 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** Prettier разбирает код в AST, строит Doc с вариантами раскладки и печатает его заново.
- **Зачем:** единая процедура выбирает переносы и отступы, сокращая споры о форме кода.
- **Как работает:** для группы печатник проверяет плоский вариант в остатке текущей строки вместе с продолжением. Не помещается — группа получает переносы; вложенные группы решают за себя.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- AST хранит структуру программы; Doc хранит куски текста, группы, отступы и места возможных переносов → «От кода к Doc».
- У сквозного send ширина 80 оставляет одну строку, 79 раскрывает внешний вызов, 38 ещё и массив, 31 ещё и format → «Печать по ширине».
- Ширина раскрывает группы снаружи внутрь; обязательный breakParent распространяет раскрытие изнутри наружу → «Печать по ширине».
- `printWidth` — ориентир, а не максимальная длина: неделимый литерал может выйти за предел → «Ширина строки».
- Комментарии, пустые строки и перенос после первой скобки объекта влияют на новый Doc → «Что остаётся».
- eslint-config-prettier отключает правила, которые спорят с печатью. Он сам не форматирует файл → «Форматтер и линтер».
- Повтор должен сохранять текст, но баги с комментариями могут менять Doc между проходами → «Идемпотентность».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `fits` учитывает закрывающие скобки и текст после группы, отступ уменьшает доступный остаток. Длины одного аргумента недостаточно.
- Литерал из примера занимает 73 колонки после переноса. При ширине 73–86 он вмещается, при 72 превышает printWidth.
- Уже раскрытый объект может остаться раскрытым после сокращения: перенос после `{` стал частью исходника следующего запуска.
- Новый патч Prettier может изменить результат: версию фиксируют точно и обновление оценивают по diff.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- group, indent, line, softline, hardline, ifBreak, fill, conditionalGroup и breakParent задают варианты печати без знания языка.
- Колонки не равны JS length: широкие символы занимают две, комбинирующие знаки могут не добавлять ширины.
- objectWrap: "collapse" позволяет сворачивать объект независимо от исходного переноса; опция появилась в 3.5.
- Алгоритм Вадлера, printDocToString, prettier --check и нестабильные случаи #20162/#20175 — в источниках темы.

</details>

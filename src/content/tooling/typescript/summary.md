# TypeScript на уровне типов

`tooling/typescript` · выжимка составлена с ИИ 2026-11-13 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** три действия компилятора — вывести тип из значения, вычислить новый тип и проверить присваивание. Аннотации и вычисления не исполняются в JavaScript.
- **Зачем:** тип описывает обещание программы; данные из JSON этому обещанию подчиняются только после исполняемой проверки. `JSON.parse` возвращает `any` и пропускает неверную форму.
- **Как работает:** условные типы выбирают ветку по присваиваемости, `infer` извлекает часть образца, mapped-типы перебирают ключи. После сборки остаются значения и явно написанные проверки.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- `type` закрыт для слияния, `interface` открыт. `enum`, namespace со значением и параметры-свойства порождают код; `const enum` подставляет значения → «Тип как вычисление».
- Сужение следует за проверками `if`/`switch`; `never` в `default` обнаруживает забытый вариант размеченного объединения → «Сужение».
- Голый параметр `T` распределяет условный тип по объединению; `[T]` проверяет объединение целиком → «Условные типы и infer».
- `[K in keyof T]` сохраняет форму массива/кортежа и модификаторы; перемена ключей через `as` меняет это поведение → «Mapped-типы».
- Накопитель делает рекурсию хвостовой; ограничение глубины не устраняет взрыв числа комбинаций → «Рекурсия и её пределы».
- Контейнер отдаёт `T`, потребитель принимает `T`; эти позиции требуют разных направлений присваивания. Бивариантные методы оставляют небезопасное исключение → «Вариантность».
- `private` проверяет TypeScript, `#` защищает движок; `implements` проверяет контракт, а декоратор порождает JavaScript → «Классы».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `x is T`, `as T` и тип ответа API сами не проверяют данные: на внешней границе нужны `unknown` и валидатор.
- `never` как пустое объединение даёт ноль веток, `any` может дать обе ветки. Проверка через `[T]` меняет этот механизм.
- С 4.4 извлечённая const-метка сужает исходный объект; с 4.6 сохраняется связь между двумя отдельно извлечёнными const-полями.
- `infer N extends number` — синтаксис 4.7; вывод числового литерала из строки появился в 4.8. `'1.0'` даёт `number`, поскольку обратная печать числа отличается.

</details>

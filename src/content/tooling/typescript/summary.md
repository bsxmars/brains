# TypeScript на уровне типов

- TypeScript проверяет отношения между типами до выполнения программы. После сборки типовые аннотации исчезают и не защищают от некорректных внешних данных.
- Условный тип выбирает ветку по присваиваемости, infer извлекает часть типового образца, mapped-тип перебирает ключи. Все они преобразуют описание допустимых значений, а не данные во время выполнения.
- `unknown` заставляет сначала проверить данные; any позволяет пропустить проверку. Утверждение as меняет мнение компилятора, но не форму JSON в памяти.
- Типы могут сузиться после исполняемой проверки, если она действительно подтверждает нужное свойство. На границах API проверяйте и структуру, и ограничения предметной области.
- Сложный тип полезен, когда проясняет контракт и выявляет ошибку у вызывающего кода. Не подменяйте им простую runtime-логику и учитывайте стоимость диагностики и поддержки.

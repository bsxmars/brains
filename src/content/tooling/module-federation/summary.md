# Микрофронтенды и Module Federation

- Module Federation загружает модуль другой сборки во время работы и согласует общие зависимости. Независимый выпуск частей приложения увеличивает число возможных сочетаний версий.
- Host получает контейнер remote, инициализирует область общих модулей и запрашивает нужный экспорт. Remote должен быть доступен и совместим в момент загрузки.
- Shared и singleton — правила выбора экземпляра, а не доказательство полной совместимости. Имеют значение диапазоны версий, момент инициализации и уже использованная копия.
- Микрофронтенды обычно делят документ, ресурсы и часть глобального состояния. Загрузка чужой сборки не создаёт изоляцию безопасности, как отдельный процесс или origin.
- Нужны явные контракты, обработка недоступности remote и контроль кеширования артефактов. Тестируйте поддерживаемые сочетания host и remote, а не только их сборку по отдельности.

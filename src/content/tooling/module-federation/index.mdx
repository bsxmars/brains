<Section variant="intro" eyebrow="Чужой код во время работы" gap={24}>
  <Callout size={19} pad="24px 26px">

    Module Federation позволяет странице загрузить модуль **из чужой сборки** по адресу —
    уже во время работы, без пересборки своей. Сама загрузка — обычный `import()`. Вся механика
    федерации существует ради другого: у host и у remote есть своя копия React, и на странице
    должна работать **одна**. Две копии одной и той же версии 19.3.0 роняют рендер
    ошибкой `Cannot read properties of null (reading 'useState')`.

  </Callout>

  Микрофронтенды — организационное решение: каждая часть интерфейса принадлежит своей команде
  и выкатывается её конвейером. Технически это значит, что страница собирается из частей,
  которые никогда не собирались вместе, и договор между ними проверяется только в браузере.

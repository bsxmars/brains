  <Callout size={19} pad="24px 26px">

    Движок исполняет бандл и ничего не знает о ваших файлах. Карта исходников — отдельный
    JSON, в котором для каждого куска бандла записано, откуда он взялся. Её читают **после**:
    отладчик, Node с флагом, сервис ошибок. Код от неё не зависит и без неё работает так же.

  </Callout>

  Сборка ломает всё, по чему человек ориентируется в коде. Два файла склеиваются в один,
  типы стираются, `checkout` становится `i`, а двадцать строк — одной. Строка и колонка
  из стека ошибки после этого указывают в бандл, где читать нечего. Карта — единственное,
  что связывает эту позицию с вашим файлом.

# Source maps изнутри

- Source map связывает позиции преобразованного кода с исходными файлами. Она помогает читать стек и отлаживать результат сборки, но не меняет исполнение JavaScript.
- Отображение задаётся отдельными сегментами, а не обязательной записью для каждого символа. Позиция между сегментами разрешается по правилам потребителя карты.
- Несколько преобразований требуют согласованной цепочки карт. Потерянная или неверная промежуточная карта может отправить ошибку на неправильную строку исходника.
- Карта должна соответствовать именно опубликованному артефакту. Совпадение имени файла без совпадения содержимого или версии не гарантирует правильный стек.
- Публикация карты и исходного текста — отдельное решение доступа. Для сервиса ошибок можно загружать карты отдельно; они не должны становиться единственным способом узнать, какой релиз выполняется.

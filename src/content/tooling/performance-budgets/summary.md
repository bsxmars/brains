# Бюджеты производительности

`tooling/performance-budgets` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** число плюс правило подсчёта, проверяемое на каждый пул-реквест.
- **Зачем:** страница тяжелеет понемногу и незаметно; проверка ловит правку до прода.
- **Как работает:** входы страницы берут из HTML; строят граф чанков (из текста, манифеста Vite или metafile esbuild); обходом в ширину считают статическое замыкание без повторного учёта общих файлов; сырые и сжатые байты получают разные бюджеты. Порог ограничивает размер, база объясняет изменение.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Артефакт, сжатое тело и transferSize — разные числа; статическое замыкание не задаёт момент загрузки; JS отдельной строкой от CSS и шрифтов → «раздел Какие байты».
- Сторож сайта: пороги по имени страницы, вес — замыкание, отдельная проверка на рантайм React → «раздел Живой бюджет».
- Регулярка путает импорт со строкой; воркеры выпадают из графа; сборщик может отдать граф файлом → «раздел Граф чанков».
- Обход в ширину даёт кратчайшую цепочку «кто тянет»; убрать модуль — разорвать все пути → «раздел Кто тянет».
- Lighthouse CI шумит и видит лишь скачанное; size-limit — для библиотек; RUM — после выката → «раздел Байты и метрики».
- Порог красит прогон, сравнение с базой — текст для человека; ложные срабатывания → «раздел Бюджет в CI».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Ссылки из HTML — ещё не всё замыкание: рендерер приводит рантайм своим `import`. `client:visible` откладывает сам вход, а import() может запуститься сразу.
- Нулевой transferSize возможен при локальном кеше или скрытых межсайтовых размерах. Gzip не сравнивают с сырым порогом как с тем же бюджетом.
- Сравнение по полному имени шумит из-за хешей; без хеша имя не уникально — одноимённые склеиваются.
- Рост общего чанка может законно превысить бюджет другой страницы. Временной порог требует стабильного стенда; в примере выбран warn.

</details>

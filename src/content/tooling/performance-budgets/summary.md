# Бюджеты производительности

- Бюджет производительности — проверяемый предел с точным способом подсчёта. «Размер страницы» без указания файлов, сжатия и момента загрузки не является однозначной величиной.
- Для начального JavaScript определите входы страницы и обойдите их статические зависимости, не считая общий файл несколько раз. Динамические загрузки учитывайте по выбранному сценарию.
- Исходные байты, передача со сжатием, выполнение JavaScript и время кадра — разные показатели. Бюджет одного из них не гарантирует остальные.
- Порог останавливает превышение, а сравнение с базовой версией объясняет, откуда взялось изменение. Отчёт должен называть конкретные файлы и пути зависимости.
- Проверяйте бюджет в воспроизводимой сборке и на важных маршрутах. Перенос кода в ленивый чанк не уменьшает цену сценария, который немедленно загружает этот чанк.

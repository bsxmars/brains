# Деревья и обход: компоновщик и итератор

`patterns/trees` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** компоновщик даёт листу и контейнеру один вызов («сколько стоит посылка»), итератор отделяет «как пройти» от самой коллекции.
- **Зачем:** глубина дерева неизвестна заранее — циклы на каждый этаж молча ошибаются на следующем.
- **Как работает:** лист отвечает сам, контейнер опрашивает детей; в JS дерево — размеченное объединение и рекурсивная функция; обход — генератор или явный стек/очередь.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- «Прозрачный» компоновщик (`addItem` у всех) против «безопасного» (только у контейнеров) → «раздел Компоновщик».
- Дерево из обычных объектов переживает JSON, лист с детьми — ошибка компиляции → «раздел Компоновщик».
- DOM — готовый «прозрачный» компоновщик, `TreeWalker` — встроенный итератор → «раздел Компоновщик».
- Коллекция — фабрика итераторов, обходы независимы → «раздел Итератор».
- Шаг назад и позиция — это курсор (массив + индекс), протокол JS ходит только вперёд → «раздел Итератор».
- Очередь вместо стека даёт обход в ширину → «раздел Обход».
- Тип id меню выводится из самого `as const`-меню, но с пределом рекурсии → «раздел Типы».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Книжный итератор сортирует сам список (`sort` на месте), а `while (it.next())` пропускает первый элемент.
- Рекурсивный обход глубокого дерева из JSON падает `RangeError`; явный стек — нет.
- `stack.push(...children)` переворачивает порядок детей.

</details>

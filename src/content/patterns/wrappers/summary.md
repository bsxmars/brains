# Обёртки: адаптер, фасад, заместитель, декоратор, мост

`patterns/wrappers` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** пять структурных паттернов, где один объект держит другой и передаёт ему вызовы; различаются целью.
- **Зачем:** объект не подходит коду, а переписывать его нельзя или дорого.
- **Как работает:** адаптер переводит интерфейс; фасад прячет несколько объектов за одним методом; заместитель с тем же интерфейсом решает, пускать ли вызов; декоратор с тем же интерфейсом добавляет работу; мост разводит две оси изменений.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Адаптер ставят потом, мост закладывают заранее → «раздел Зачем».
- С зависимостью от интерфейса адаптер — один объект или функция на границе с API → «раздел Адаптер».
- Фасад не должен прятать неудачу; естественный фасад — модуль → «раздел Фасад».
- Класс-заместитель закрыт по умолчанию, встроенный `Proxy` — открыт → «раздел Заместитель».
- Кешировать промис, а не значение, — правильно: два одновременных вызова дают один запрос → «раздел Заместитель».
- Порядок обёрток в стопке — это поведение → «раздел Декоратор».
- Мост: классов — сумма вместо произведения → «раздел Мост».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `fetch` на 500 выполняется с `ok: false`, а `res.json()` — `Promise<any>`; без проверки `res.ok` ошибка выдаётся за данные.
- Кеш промисов хранит отказ: одна сетевая ошибка — до перезагрузки.
- «Декоратор», меняющий переданный объект, — не обёртка; спред теряет методы класса.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- `private`-поле делает класс номинальным — книжный адаптер вынужден наследовать базу (`ts(2345)`) → «раздел Адаптер».
- `promisify(store.load)` теряет `this` → `TypeError`; лечится `bind` → «раздел Адаптер».
- Новый метод интерфейса: класс-заместитель — `ts(2420)`, `Proxy` пропускает к цели → «раздел Заместитель».
- Лечение кеша: `p.catch(() => cache.delete(id))` → «раздел Заместитель».
- `@`-декораторы применяются снизу вверх, вызываются сверху вниз; в Node 26.8.2 синтаксиса нет → «раздел Декоратор».
- Vue: `createRenderer(extend({ patchProp }, nodeOps))`; у React — host config в `react-reconciler` → «раздел Мост».

</details>

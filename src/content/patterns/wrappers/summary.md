# Обёртки: адаптер, фасад, заместитель, декоратор, мост

- Адаптер переводит один интерфейс в другой; фасад даёт простой вход к нескольким подсистемам; заместитель управляет доступом; декоратор добавляет поведение; мост разделяет две независимые оси изменений.
- Обёртка хранит зависимость и передаёт ей вызовы. Сохранение интерфейса ещё не гарантирует сохранения поведения: важны ошибки, порядок вызовов и побочные эффекты.
- На границе API проверьте HTTP-статус, разберите тело и проверьте форму данных. Тип TypeScript не превращает неизвестный JSON в корректный объект.
- Порядок обёрток меняет результат: кеш вокруг повтора запроса и повтор вокруг кеша имеют разные правила. Заранее определите, какие результаты и ошибки сохраняются.
- Повтор запроса может повторить внешний эффект. Кеш обещаний должен иметь политику удаления отказов; обёрнутые методы должны сохранять нужный this.

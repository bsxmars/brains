# Поведение как значение: стратегия, команда, шаблонный метод, состояние

- Стратегия заменяет способ выполнения одной операции; команда представляет отдельное действие; шаблонный метод фиксирует порядок шагов; состояние определяет допустимые действия и переходы.
- В JavaScript поведением часто служит функция. Команду стоит хранить данными, если её нужно записывать, повторять или передавать; классы выбирают по контракту задачи.
- Модель состояния должна запрещать недопустимые переходы. Идентификатор попытки связывает асинхронный результат именно с той операцией, которая ещё актуальна.
- Асинхронные шаги нужно явно ожидать и обрабатывать их отказы. Тип void не заставляет вызывающий код ждать Promise, а переданный метод может потерять this.
- Отмена локальной команды не отменяет отправленный платёж или серверную запись. Игнорирование старого ответа защищает интерфейс; порядок внешних эффектов требует отдельного протокола.

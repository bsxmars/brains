# Поведение как значение: стратегия, команда, шаблонный метод, состояние

`patterns/behavior` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** четыре паттерна, которые вынимают действие из объекта в отдельную передаваемую вещь.
- **Зачем:** убрать лестницу `if` по вариантам из каждого метода; в JS функция — значение, и половина паттернов сводится к колбэку.
- **Как работает:** стратегия — функция; команда — замыкание `{ execute, undo }` или данные `{ type }`; шаблон — порядок шагов в одной функции; состояние — размеченное объединение или таблица переходов.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Набор стратегий под `satisfies` сохраняет ключи → «раздел Стратегия».
- Компаратор `sort` — встроенная стратегия, устойчивость держит составной порядок → «раздел Стратегия».
- Откат запоминает «как было» в момент выполнения, а не создания → «раздел Команда».
- Команда для очереди или сети — только данные, как действия Redux → «раздел Команда».
- Шаблон без наследования: шаги объектом → «раздел Шаблонный метод».
- Размеченное объединение не даёт собрать невозможное состояние → «раздел Состояние».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Переданный метод теряет `this`; `this`-параметр не спасает, пока тип колбэка не объявит `this: void`.
- `async`-шаг под `void` компилируется, не ожидается, отказ роняет процесс мимо `try`.
- Общее состояние с `setContext` публикует чужой документ.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- `(a, b) => a > b` в V8 не переставляет ничего → «раздел Стратегия».
- Замыкание: `JSON.stringify` → `{}`, `structuredClone` → `DataCloneError`; Redux 5 отвергает экземпляр класса → «раздел Команда».
- `override` + `noImplicitOverride` ловят переименованный шаг (`ts(4113)`) → «раздел Шаблонный метод».
- Шаблон из конструктора базы не видит полей наследника → «раздел Тонкие места».
- Тип `Machine` для таблицы переходов → «раздел Состояние».

</details>

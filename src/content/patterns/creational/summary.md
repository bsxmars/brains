# Создание объектов: фабрика, строитель, прототип, одиночка

- Фабрика выбирает, какой объект создать; строитель собирает его по шагам; прототип создаёт копию; одиночка ограничивает число экземпляров в выбранной области.
- В JavaScript функцию или класс можно передать как значение. Отдельная иерархия классов нужна, только если она упрощает контракт создания.
- Фабрика должна принимать известный набор вариантов и явно отклонять неизвестные. Реестр в Map не подхватывает унаследованные свойства обычного объекта.
- Определите, какие части копии независимы: поверхностное копирование сохраняет ссылки на вложенные объекты. Изменение такой копии может изменить оригинал.
- Область жизни важнее слова «одиночка»: модуль, глобальный объект, процесс и запрос — разные границы. Пользовательское состояние нельзя разделять между запросами; globalThis не объединяет разные realm.

# Один манифест на много окружений: Helm, Kustomize и GitOps

`delivery/helm-gitops` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** способы описать общее один раз, а у каждого окружения записать только отличия; GitOps — доставка, где кластер сам тянет состояние из Git.
- **Зачем:** три папки копий расходятся, и stage перестаёт проверять то, что поедет в prod; образ один на все окружения.
- **Как работает:** Kustomize накладывает на базу слои с патчами → Helm заполняет шаблоны значениями из `values.yaml`, `-f` и `--set` → контроллер в кластере (Argo CD, Flux) собирает манифесты из Git, сверяет и применяет разницу; откат — `git revert`.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Окружения отличаются только данными; `VITE_*` вписывается в бандл при сборке → «раздел Три окружения».
- `images`, `namePrefix` с переписыванием ссылок, генератор ConfigMap с хешем в имени → «раздел Kustomize».
- Strategic merge сливает списки по ключу из схемы типа, JSON 6902 — операции по адресу → «раздел Патчи».
- Шаблон — текст, а не YAML; `default`, `toYaml | nindent`, `with`, `quote`, `required` → «раздел Helm: шаблоны».
- Словари сливаются вглубь, списки заменяются → «раздел Values».
- Ревизии в кластере, `rollback` как новая ревизия, хук `pre-upgrade` для миграции → «раздел Релиз и откат».
- Push против pull, дрейф, `selfHeal`, `prune`; секреты в Git — Sealed Secrets, SOPS, External Secrets → «раздел GitOps», «раздел Секреты в Git».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Список из файла окружения заменяет базовый целиком — пропадает контейнер или переменная.
- Сменили ConfigMap — поды со старыми настройками, пока нет хеша в имени или аннотации с контрольной суммой.
- `replicas: 0` с `default` даёт значение по умолчанию; опечатка в ключе values молчит.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Порядок values: `values.yaml` → `-f` (правый сильнее) → `--set` → «раздел Values».
- `--set` угадывает тип; строки — `--set-string` или `| quote` → «раздел Values».
- История — Secret `sh.helm.release.v1.<имя>.v<N>`, по умолчанию 10 ревизий; `--wait`, `--atomic` → «раздел Релиз и откат».
- `APP VERSION` берётся из `Chart.yaml`, а не из реального образа → «раздел Релиз и откат».
- Argo CD опрашивает Git раз в три минуты, `prune` выключен по умолчанию, Helm без релиза → «раздел GitOps».
- `commonLabels` пишет в неизменяемый селектор → «раздел Тонкие места».

</details>

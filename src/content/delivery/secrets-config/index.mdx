  <Callout size={19} pad="24px 26px">

    Всё, что попало в клиентский бандл, **публично** — с префиксом и без, при сборке или при
    запуске. Секрету во фронтенде не место вовсе. А на сервере переменная окружения — самое
    удобное и самое разговорчивое место для секрета: её копируют, печатают и хранят дольше, чем
    кажется.

  </Callout>

  Браузер не умеет читать переменные окружения, поэтому сборщик подставляет их значения прямо
  в код. Это удобно для адреса API и смертельно для пароля базы. Защита у сборщиков одна —
  список имён, которые разрешено подставлять, — и её легко снять одной строкой конфига, даже
  не заметив.

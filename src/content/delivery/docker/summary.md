# Docker: образ и слои

- Образ содержит файловые слои и конфигурацию запуска, а контейнер — отдельный запущенный экземпляр с доступным ему окружением и слоем записи.
- Сборка переиспользует шаги по ключам кеша. Изменение значимого входа заставляет пересобрать зависимую часть; порядок копирования файлов влияет на объём этой работы.
- Multi-stage позволяет отделить инструменты сборки от файлов runtime. Удаление секрета поздней инструкцией не убирает его из уже сохранённого слоя.
- Контейнер не является виртуальной машиной с собственным ядром. Изоляция, ограничения ресурсов, права пользователя и доступные устройства задаются отдельно.
- Данные, которые должны переживать замену контейнера, хранят вне его временного слоя. Для воспроизводимого выпуска важны неизменяемые версии зависимостей и идентичность образа по digest.

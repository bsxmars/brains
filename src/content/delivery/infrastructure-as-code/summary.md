# Инфраструктура как код: Terraform и OpenTofu

- Infrastructure as Code описывает желаемые ресурсы и связи между ними. Terraform сопоставляет конфигурацию с реальными объектами через state и провайдеров.
- Plan сравнивает конфигурацию, состояние и доступную картину внешнего мира. Изменение может требовать обновления на месте или замены — это определяет конкретный ресурс провайдера.
- Граф зависимостей задаёт порядок действий и возможный параллелизм. Ссылка на результат другого ресурса важнее случайного порядка блоков в файле.
- Apply не является общей транзакцией инфраструктуры: часть действий может успеть выполниться до отказа. После сбоя нужно согласовать state и фактический мир, а не считать всё отменённым.
- State и планы требуют контроля доступа, блокировки совместной записи и резервирования. Они могут содержать чувствительные данные; пометка sensitive не равна шифрованию или удалению секрета.

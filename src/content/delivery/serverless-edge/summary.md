# Serverless и edge: холодный старт и границы рантайма

- Serverless передаёт платформе запуск и масштабирование экземпляров. Edge описывает близость размещения к пользователю, но не один обязательный runtime или набор API.
- Новый экземпляр должен инициализироваться, а тёплый может переиспользовать память. Ни сохранение конкретного экземпляра, ни единственный глобальный экземпляр не гарантируются.
- Состояние между вызовами храните во внешнем надёжном источнике, если оно необходимо для корректности. Локальный кеш полезен лишь как ускорение с ограниченным сроком жизни.
- Масштабирование функций может увеличить число соединений к базе быстрее её возможностей. Предел параллелизма, пул соединений и обратное давление остаются задачами архитектуры.
- Проверяйте лимиты времени, памяти, API и размещения данных конкретной платформы. Повторы событий и вызовов требуют идемпотентности независимо от способа запуска функции.

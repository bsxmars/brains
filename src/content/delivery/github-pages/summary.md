# GitHub Pages: публикация статики

- GitHub Pages публикует заранее собранные файлы. Серверный код приложения там не исполняется, поэтому маршруты, данные и интерактивность должны соответствовать статическому хостингу.
- Конвейер собирает дерево сайта и передаёт его как артефакт публикации. Успешная локальная сборка и корректный опубликованный артефакт — разные проверки.
- Сайт проекта может находиться под префиксом репозитория. Настройка base влияет на пути сборщика, но не исправляет любую строку URL, записанную вручную.
- Прямой переход на адрес должен находить подходящий файл или предусмотренную страницу ошибки. Клиентский роутер сам по себе не настраивает серверные перенаправления.
- Проверяйте сайт с тем же префиксом, что при публикации: ресурсы, ссылки, обновление вложенного адреса и кеширование. Требования к произвольным заголовкам или backend могут потребовать другого хостинга.

# Вход в кластер: Ingress и Gateway API

- Ingress и Gateway API описывают правила входящего трафика, а контроллер исполняет их. Один созданный объект API не запускает прокси автоматически.
- Маршрут выбирается по настроенным listener, host и path. DNS, внешний адрес, TLS и доступность backend — отдельные части пути запроса.
- Service связывает логический адрес с экземплярами приложения, а EndpointSlice сообщает адреса и условия готовности. Способ пересылки зависит от контроллера и сети кластера.
- Проверьте, какие правила приняты и к каким ресурсам они прикреплены. Неоднозначные пути, class и ссылки между namespace могут менять результат или блокировать маршрут.
- Заголовки о клиенте заслуживают доверия только от доверенного прокси. Аутентификацию, таймауты, лимиты и поведение долгих соединений задавайте явно.

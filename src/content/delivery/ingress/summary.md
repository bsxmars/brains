# Вход в кластер: Ingress и Gateway API

`delivery/ingress` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** вход — прокси в кластере с правилами «хост и путь → сервис»; правила пишут в Ingress или Gateway API, исполняет отдельный контроллер.
- **Зачем:** сервис работает на L4 и не видит хост и путь; вход даёт один внешний адрес на весь кластер и выбор приложения по HTTP.
- **Как работает:** DNS → балансировщик L4 у контроллера → контроллер расшифровывает TLS, находит правило и выбирает сервис → берёт адреса готовых подов из EndpointSlice и шлёт запрос прямо поду.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Четыре посредника, HTTP читает только контроллер входа → «раздел Путь запроса».
- `Prefix` сравнивает сегменты; выигрывает самый длинный путь, при равной длине `Exact` → «раздел Ingress: хост и путь».
- Без контроллера Ingress ничего не делает; класс выбирает контроллер, аннотации понимает только свой → «раздел Класс и аннотации».
- TLS кончается на входе, сертификат в Secret, выпуск и продление — cert-manager → «раздел TLS и сертификаты».
- Gateway API: роли `GatewayClass`/`Gateway`/`HTTPRoute`, условия, веса, фильтры, статус маршрута → «раздел Gateway API».
- Фолбэк SPA — работа сервера статики, а не входа; WebSocket живёт по таймаутам входа → «раздел SPA, кеш, WebSocket».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Пустой `ADDRESS` — объект не взял ни один контроллер, ошибки нет.
- Смена контроллера молча стирает настройки из аннотаций; `use-regex` действует на все пути хоста.
- Приложение за входом думает, что работает по HTTP: без доверия `X-Forwarded-Proto` — редиректы на `http://` и нет `Secure`-куки.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- ingress-nginx: `proxy-body-size` 1m (413), таймауты 60 с, `ssl-redirect` даёт 308 → «раздел Класс и аннотации».
- Звёздочка: в Ingress ровно одна метка, в Gateway API одна и больше → «раздел Тонкие места».
- В HTTPRoute `Exact` сильнее любого префикса; нет совпадения — обязан 404 → «раздел Gateway API».
- Маршрут не прицепился: `Accepted: False`, `NotAllowedByListeners` → «раздел Тонкие места».
- cert-manager продлевает после двух третей срока; звёздочка только через DNS-01 → «раздел TLS и сертификаты».
- ingress-nginx без поддержки после марта 2026; Gateway API стабилен с v1.0 → «раздел Gateway API».

</details>

# Vue 3 изнутри: рендерер и patch

- Patch сопоставляет старые и новые VNode по типу и key. Совместимый узел обновляется, несовместимый заменяется; VNode описывает результат, а хост выполняет операции.
- Компилятор сообщает renderer, какие части шаблона могут измениться. Это позволяет пропускать статические участки и проверять нужные свойства, а не весь DOM без разбора.
- Для списка с ключами Vue сохраняет подходящие элементы и отдельно обрабатывает вставки, удаления и перемещения. Уникальный устойчивый key обозначает идентичность данных.
- LIS помогает сократить перемещения сохранившихся узлов в изменившейся середине списка. Создание нового элемента и перенос уже существующего имеют разную цену.
- Повторный render не обязательно меняет DOM. Учебный хост показывает операции renderer, но стоимость layout, paint и реального компонента нужно измерять в браузере.

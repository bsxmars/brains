# Vue 3 изнутри: рендерер и patch

`frameworks/vue-patch-internals` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** `patch` сравнивает старое и новое дерево VNode и отдаёт хосту только разницу.
- **Зачем:** двигать настоящие узлы дорого, сравнивать объекты дёшево.
- **Как работает:**
  1. Тот же `type` + `key` — сверить; иначе снять и смонтировать на то же место.
  2. Дети с ключами: края с начала и конца, середина — через карту ключей.
  3. LIS по старым индексам не двигается, остальные переставляются справа налево.
  4. Флаги компилятора и блоки пропускают статику.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Форма узла считается один раз и проверяется битом → «раздел VNode».
- Хост — десяток функций; вставка уже вставленного узла = перемещение → «раздел mount и patch».
- Без ключей — по позиции: состояние узла остаётся, данные уезжают → «раздел Без ключей».
- Правило React жадное, минимума не даёт → «раздел С ключами».
- Блок — плоский список динамики, обход пара к паре; `v-if`/`v-for` открывают свои блоки → «раздел Флаги и блоки».
- Компонент — эффект через очередь; ребёнок с новым пропсом обновляется синхронно внутри patch родителя → «раздел Компонент».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `:key="index"` = нет ключа; дубликат ключа молча оставляет лишний узел.
- Флаг — обещание, рендерер не смотрит остальное. Без `patchFlag > 0` отрицательные флаги проходят любую проверку бита.
- LIS не спасает разворот; проход слева направо ломает порядок.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- `li` с текстом: `shapeFlag = 9` → «раздел VNode».
- `ABCDEFG → ABECDHFG`: `[5, 3, 4, 0]`, LIS — C и D; перемещений Vue/без LIS/React = 1/3/2 → «раздел С ключами».
- `TEXT` 1, `CLASS` 2, `PROPS` 8, `KEYED_FRAGMENT` 128, `CACHED` −1, `BAIL` −2 → «раздел Флаги и блоки».
- `runner.effect.dirty && runner()` гасит двойной рендер; очередь по `uid` → «раздел Компонент».

</details>

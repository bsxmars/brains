# React изнутри: свой рендерер и хуки

`frameworks/react-internals` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** мини-React по шагам, сверенный тестом с React 19.3.
- **Зачем:** правила React — следствия пары строк кода; видно, что именно сломается при нарушении.
- **Как работает:**
  1. JSX — вызов `createElement`, результат — объект `{ type, key, props }`.
  2. Рендер обходит файберы по одному (вниз, вбок, вверх) и может прерваться между ними.
  3. Render строит второй буфер; коммит одним куском применяет его и меняет буферы ролями.
  4. Хук находит ячейку по номеру вызова; `setState` пишет в очередь и ставит одну микрозадачу.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- `key` не попадает в пропсы; `null`/`false`/`true` выбрасываются → «раздел Элемент».
- Обход хранится в указателях файбера и закладке, а не в стеке вызовов → «раздел Файбер и цикл».
- Рендерер рисует только через host config; узлы создаются в render-фазе вне документа → «раздел Две фазы».
- Тип решает, ключ сопоставляет; другой тип — поддерево заново со всем состоянием → «раздел Сверка».
- Батчинг — флаг и одна микрозадача; новое обновление бросает недостроенное дерево → «раздел Батчинг».
- Эффекты: layout внутри коммита, `useEffect` отдельной задачей, сначала все очистки → «раздел Эффекты».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Хуков стало больше — ошибка; поменялся порядок двух `useState` — тишина, значения меняются местами.
- Очистки при удалении идут сверху вниз, а эффекты монтирования — снизу вверх.
- Вызов компонента может быть выброшен — тело обязано быть чистым.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Коммит: удаления → вставки/правки → смена буферов → layout → `useEffect` позже → «раздел Две фазы».
- Три `setN(c => c + 1)` дают `3`, три `setN(n + 1)` — `1` → «раздел Хуки».

</details>

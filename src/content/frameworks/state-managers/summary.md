# Стейт-менеджеры изнутри

`frameworks/state-managers` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** стор — переменная с состоянием плюс набор подписчиков, которых зовут при изменении.
- **Зачем:** вынести общие данные из компонентов, не будя всех на каждое изменение.
- **Как работает:** Redux после каждого `dispatch` зовёт всех; Zustand зовёт всех, если сменилась ссылка состояния, а селектор + `Object.is` отсекает чужое; Pinia — `reactive`-объект, Vue сам помнит, кто какое поле читал, и будит только их.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Стор сравнивает одну ссылку, не содержимое: новый объект с тем же значением — уведомление → «раздел Стор».
- Мутация в reducer прячет изменение от сравнения ссылок; Immer в Toolkit копирует только путь к изменённому полю → «раздел Redux».
- Селектор вызывается на каждое уведомление, слушатель — только при новом куске; `shallow` сравнивает по полям → «раздел Селектор».
- В Zustand 5 селектор — это `getSnapshot` в `useSyncExternalStore`, сравнивает React → «раздел Zustand».
- Pinia: та же запись не будит никого, несколько записей — один рендер → «раздел Pinia».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Селектор, строящий новый объект (в т.ч. `.map`/`.filter`), в Zustand 5 — бесконечный цикл и падение всего дерева; в Zustand 4 и `useSelector` — лишний рендер. Лечение: `useShallow` или селектор на поле.
- `useApp()` без селектора перерисовывает на любой `set`, даже с тем же значением.
- Деструктуризация стора Pinia — снимок навсегда; для полей нужен `storeToRefs`.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Zustand не зовёт подписчиков только на `set((s) => s)`; Redux зовёт и на незнакомое действие → «раздел Redux».
- Объектный селектор: 5 вызовов, 4 слушателя; с `shallow` — 2 → «раздел Селектор».
- Цикл: «Maximum update depth exceeded» (прод — #185) → «раздел Zustand».
- RTK: состояние заморожено, проверка мутаций только в разработке → «раздел Redux».
- `$subscribe`: по умолчанию раз за очередь, `flush: 'sync'` — на каждую запись → «раздел Pinia».

</details>

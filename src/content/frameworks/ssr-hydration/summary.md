# SSR и гидратация: React и Vue

- SSR создаёт начальный HTML на сервере. Гидратация запускает клиентское дерево поверх готового документа и подключает поведение; до неё нативные ссылки и формы могут работать сами.
- HTML ускоряет появление содержимого, но не делает клиентский JavaScript бесплатным. Код всё ещё нужно загрузить, разобрать и выполнить, а дерево — связать с существующими узлами.
- Серверный и первый клиентский результаты должны совпадать. Случайность, время, разные данные и обращения к браузерным API во время рендера могут вызвать расхождение.
- Способ восстановления после несовпадения зависит от фреймворка и границ дерева. Не используйте исправление hydration mismatch как обычный способ обновить данные.
- SSR-код выполняется без window и DOM страницы. Побочные действия и браузерные зависимости размещайте в подходящем клиентском жизненном цикле; потоковая выдача не отменяет этих требований.

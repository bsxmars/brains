# SSR и гидратация: React и Vue

`frameworks/ssr-hydration` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** сервер отдаёт строку HTML; гидратация — первый рендер в браузере, который не создаёт узлы, а забирает готовые.
- **Зачем:** убрать белый экран до загрузки бандла. Цена — окно «видно, но не работает» и риск расхождения сервера и клиента.
- **Как работает:** сервер рендерит без эффектов → фреймворк идёт по дереву и сверяет узел со следующим узлом документа → совпал — забирает → иначе: React перерисовывает до ближайшей границы `Suspense` (нет — весь корень), Vue латает узел.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Служебные комментарии-маркеры в серверном HTML → «раздел Что отдаёт сервер».
- React гидратирует отдельной задачей, но клик в промежутке гидратирует синхронно; Vue — синхронно → «раздел Гидратация».
- Позиционная сверка Vue: лишний узел заменяет весь хвост → «раздел Несовпадения».
- React стримит каркас и досылает куски в тот же ответ; Vue — по порядку, ждёт медленное → «раздел Стриминг».
- Выборочная гидратация: тронутая граница — первой → «раздел Стриминг».
- Ленивая гидратация Vue откладывает оживление, острова — ещё и код; Server Components не гидратируются → «раздел Ленивая гидратация», «раздел Цена».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Атрибуты не чинит никто, в продакшене — молча.
- `suppressHydrationWarning` оставляет серверное значение; `data-allow-mismatch` молчит, но исправляет.
- React 19 теряет клик, если код границы не приехал; Vue с `hydrateOnInteraction` повторяет событие, но грузит код сразу.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- `<!-- -->`, `<!--$-->`/`<!--$?-->`/`<!--$!-->` (React), `<!--[-->…<!--]-->` (Vue) → «раздел Что отдаёт сервер».
- Без границы 10 узлов заново, с границей — 4 → «раздел Тонкие места».
- React `#418` через `onRecoverableError`; Vue — одна строка раз на страницу → «раздел Несовпадения».
- `$RC("B:0","S:0")`, вставка не раньше 300 мс после первого кадра → «раздел Стриминг».

</details>

# Ре-рендеринг в React

`frameworks/react-rerender` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** ре-рендер — повторный вызов функции компонента, а не перерисовка страницы.
- **Зачем:** React не знает, кто что читает, — выясняет пересчётом и сравнением, DOM правит только по разнице.
- **Как работает:**
  1. `setState` помечает фибер и ставит `childLanes` предкам до корня.
  2. По умолчанию вызываются все функции ниже помеченного.
  3. Bailout: тот же объект пропсов, контекст тот же, работы нет; пустой `childLanes` — поддерево пропущено.
  4. Render можно выбросить, commit идёт одним куском — отсюда требование чистоты.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- `useLayoutEffect` — до кадра; момент `useEffect` зависит от причины обновления → «раздел Модель».
- Опустить состояние вниз и передать элемент через `children` — пропуск без `memo`; контекст идёт мимо `memo` → «раздел Дерево».
- Компонент, объявленный внутри компонента, перемонтируется каждый рендер → «раздел Дерево».
- `key={index}` отдаёт старые фиберы другим элементам списка; смена `key` — приём сброса состояния → «раздел Ключи».
- Батчинг везде с React 18; нарезка — только несрочного рендера, коммит не режется → «раздел Батчинг и нарезка».
- `useMemo`/`useCallback` полезны только с `memo` и стабильностью всех пропсов → «раздел Мемоизация».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `memo` не защищает от собственного `setState`, контекста и хуков внешнего стора.
- Мемоизация не помогает на первом рендере: сравнивать не с чем.
- В cleanup `ref.current` уже обнулён — узел сохраняют заранее.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Три `setState` в обработчике, промисе, `setTimeout` — один рендер, через `flushSync` — три → «раздел Батчинг и нарезка».
- Из восьми сочетаний `memo`/`useMemo`/`useCallback` ребёнок пропускается в одном → «раздел Мемоизация».
- Фазы `onRender`: `mount`, `update`, `nested-update`; в продакшене зовётся только с `react-dom/profiling` → «раздел Мемоизация».

</details>

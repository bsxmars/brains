<Section variant="intro" eyebrow="Кто даёт зависимость" gap={24}>
  <Callout size={19} pad="24px 26px">

    Класс не создаёт то, что ему нужно, а **просит по имени**. Ответ даёт дерево над ним:
    ближайшее место, где для этого имени записан провайдер. Поменяли провайдер — поменялся
    ответ, а код того, кто просит, остался прежним.

  </Callout>

  Во всех трёх фреймворках это одна идея: компонент называет токен, а значение находится
  поиском вверх по дереву компонентов. Различаются правила поиска. Angular держит отдельный
  инжектор у каждого элемента с компонентом, умеет создавать объекты сам и понимает флаги
  «только у себя», «начиная с родителя», «не дальше хоста». Vue хранит провайдеры в объектах,
  связанных прототипами, и ищет оператором `in`. React берёт ближайший `<Ctx value>` выше.

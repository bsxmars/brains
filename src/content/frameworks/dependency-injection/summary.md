# Внедрение зависимостей

`frameworks/dependency-injection` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** компонент просит зависимость по токену, а значение находится поиском вверх по дереву — у ближайшего провайдера.
- **Зачем:** заменить реализацию (тест, другой бэкенд) в одном месте, дать экземпляр на поддерево, не пробрасывать через пропсы.
- **Как работает:**
  1. Vue: `provides` компонента — ссылка на родительский; первый `provide` делает `Object.create(parent)`; поиск — `key in`.
  2. React: ближайший `<Ctx value>` выше, иначе значение из `createContext`.
  3. Angular: вверх по `ElementInjector`, потом по окружениям до `NullInjector`; экземпляр создаётся лениво, один на инжектор.
  4. Флаги Angular меняют, где начать, где остановиться и что вернуть вместо ошибки.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Значение по умолчанию и фабрика в `inject`; реактивность даёт `ref`, не `inject` → «раздел Vue».
- Новый объект в `value` перерисовывает всех читателей; `use` можно звать после условия → «раздел React».
- Два вида инжекторов, блум-фильтр, `providedIn: 'root'` и tree-shaking → «раздел Инжекторы Angular».
- Четыре рецепта провайдера, `multi`, `InjectionToken`, `viewProviders` → «раздел Провайдеры и флаги».
- Учебный инжектор: запись с меткой, цикл по метке → «раздел Своими руками».
- В продакшене от ошибок остаются только коды → «раздел Ошибки».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Во Vue и React компонент не видит своё `provide`, только родительское; в Angular видит свои `providers`.
- Зависимости `providedIn: 'root'` ищутся от корня, а не от того, кто попросил.
- `NG0200` после `NG0201`: окружение не снимает метку «создаётся» — чинить первую ошибку.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- `inject(key, default, true)` — фабрика; `undefined` перекрывает запасное → «раздел Vue».
- Блум-фильтр на 256 бит; `NOT_YET` → «раздел Инжекторы Angular».
- `useValue`/`useClass`/`useFactory`/`useExisting`; `multi` не складывает уровни → «раздел Провайдеры и флаги».
- `optional`, `self`, `skipSelf`, `host` (видит только `viewProviders` хоста) → «раздел Провайдеры и флаги».
- `NG0200` цикл, `NG0201` нет провайдера, `NG0203` вне контекста внедрения → «раздел Ошибки».

</details>

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** компилятор превращает шаблон в клон готового HTML и эффекты на узлах, а руны — в граф сигналов рантайма.
- **Зачем:** обойтись без виртуального DOM и повторного вызова компонента: он выполняется один раз.
- **Как работает:** запись ничего не считает — помечает читателей «грязными», даёт записи номер, заводит пакет → в микрозадаче сброс выполняет помеченные эффекты: шаблонные, потом `$effect` → «возможно грязный» сверяет номера записей зависимостей.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Вывод компилятора: клон HTML, путь к узлам арифметикой, проп — геттер родителя → «раздел Вывод компилятора».
- Один счётчик записей на всё приложение вместо версий на каждой связи → «раздел Граф и флаги».
- Пакет — весь синхронный код до микрозадачи; `flushSync` сбрасывает сразу → «раздел Пакет и сброс».
- `$state` с объектом — Proxy, источник на каждое свойство; `$state.raw` следит только за заменой целиком → «раздел Proxy и raw».
- Производное — в `$derived`, `$effect` — для выхода наружу, с очисткой → «раздел $effect и $derived».
- `{#each}` с ключом переносит узлы, без ключа переписывает тексты → «раздел Списки с ключом».
- `let`/`$:` в режиме совместимости: зависимости из текста, выполняется до DOM → «раздел Против Svelte 4».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `push` в `$state.raw` меняет данные молча — всплывёт при следующей замене.
- Синхронизация через `$effect` — шаблон дважды и кадр с несогласованной парой.
- Класс, `Map`, `Date` в `$state` внутри не отслеживаются; прокси не пишет в исходный объект (у Vue наоборот).

</details>

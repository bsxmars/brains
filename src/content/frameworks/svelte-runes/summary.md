# Svelte 5 изнутри

`frameworks/svelte-runes` · выжимка обновлена 2026-11-12.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** компилятор превращает шаблон в клон готового HTML и эффекты на узлах, а руны — в граф сигналов рантайма.
- **Зачем:** обойтись без виртуального DOM и повторного вызова компонента: он выполняется один раз.
- **Как работает:** обычная запись помечает реакции и откладывает эффекты, но чтение устаревшего derived может пересчитать его синхронно. При сбросе номера изменений помогают пропустить эффект, если derived остался прежним.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Вывод компилятора: клон HTML, путь к узлам посчитан заранее, проп — геттер родителя → «раздел Вывод компилятора».
- Один счётчик записей на всё приложение вместо версий на каждой связи → «раздел Граф и флаги».
- Пакет — весь синхронный код до микрозадачи; `flushSync` сбрасывает сразу → «раздел Пакет и сброс».
- `$state` с объектом — Proxy, источник на каждое свойство; `$state.raw` следит только за заменой целиком → «раздел Proxy и raw».
- Производное — в `$derived`, `$effect` — для выхода наружу, с очисткой → «раздел $effect и $derived».
- `{#each}` с ключом переносит узлы, без ключа переписывает тексты → «раздел Списки с ключом».
- `let`/`$:` в режиме совместимости: зависимости из текста, выполняется до DOM → «раздел Против Svelte 4».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `push` в `$state.raw` меняет данные молча — всплывёт при следующей замене.
- В показанном сценарии синхронизация через effect даёт два вычисления шаблона и промежуточную несогласованную пару. Журнал не доказывает, что браузер показал отдельный кадр человеку.
- Класс, `Map`, `Date` в `$state` внутри не отслеживаются; прокси не пишет в исходный объект (у Vue наоборот).

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Демо исполняет мини-руны; рядом сохранён журнал настоящего Svelte, повторяемый тестом. Биты `CLEAN`/`DIRTY`/`MAYBE_DIRTY`, сверка `dep.wv > reaction.wv` → «раздел Граф и флаги».
- В сценарии отсечки n: 1 → 3 пересчитывает odd, но true остаётся true и пользовательский эффект пропускается → «раздел Граф и флаги».
- Больше 1000 проходов — `effect_update_depth_exceeded`; запись из `$derived` — `state_unsafe_mutation` → «раздел Тонкие места».

</details>

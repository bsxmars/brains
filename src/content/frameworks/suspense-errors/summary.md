# Suspense и границы ошибок

- Suspense задаёт интерфейс ожидания поддерживаемого асинхронного чтения во время render. Error Boundary задаёт запасной интерфейс для ошибки в охватываемом дереве.
- Ожидание и отказ идут к границам разных типов. После завершения ожидания React может заново начать вычисление поддерева; частично выполненный render не следует считать завершённым.
- Граница ожидания не начинает любой запрос автоматически. Источник данных должен поддерживать согласованное чтение, повторное использование и обработку результата.
- Границы определяют, какая часть экрана заменяется и что остаётся доступным. Размещайте их по независимым участкам интерфейса, а не вокруг каждого мелкого элемента без причины.
- Error Boundary не заменяет try/catch для событий и произвольной асинхронной работы. Для повторной попытки нужны и сброс состояния границы, и исправление или обновление источника ошибки.

# Suspense и границы ошибок

`frameworks/suspense-errors` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** «данных нет» и «сломалось» — оба `throw` из рендера: промис ловит `<Suspense>`, ошибку — граница ошибок.
- **Зачем:** компонент вызывает фреймворк, `try/catch` вокруг него бесполезен; граница решает, что показать вместо ждущего или упавшего поддерева.
- **Как работает:** бросок летит вверх до ближайшей границы своего типа, чужую пропускает → граница показывает заглушку → когда промис выполнен, содержимое границы рендерится заново с начала.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Компонент не продолжается с места остановки; после заглушки React прогревает соседей → «раздел Бросок».
- Промис должен переживать рендер: кеш, библиотека данных, сервер → «раздел Стабильный промис».
- Ждущий родитель задерживает загрузку детей; лечится стартом запросов раньше → «раздел Водопад».
- Переход держит старое содержимое вместо заглушки → «раздел Переходы».
- Граница ошибок — класс с двумя методами; обработчики событий и async не ловит → «раздел Граница ошибок».
- Три колбэка корня React 19; непойманное снимает весь корень → «раздел Ошибки у корня».
- Vue: `async setup` + `<Suspense>`, `onErrorCaptured` у любого предка, ловит и обработчики → «раздел Vue».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `use(fetch(…))` в теле — вечная заглушка без ошибки: каждый повтор создаёт новый промис.
- Граница не ловит саму себя и сама не сбрасывается — перемонтируют через `key`.
- Без `<Suspense>` выше: React ждёт всем корнем, Vue с `async setup` рисует пустоту навсегда.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Порядок: бросок → синхронный повтор корня → `getDerivedStateFromError` → коммит → `onCaughtError` → `componentDidCatch` → «раздел Граница ошибок».
- Асинхронную ошибку несут в рендер через `setState(() => { throw error })` → «раздел Граница ошибок».
- По умолчанию: непойманные — `reportError`, пойманные — `console.error` → «раздел Ошибки у корня».
- Vue: `return false` останавливает всплытие; `:timeout` у `<Suspense>`; без `errorHandler` отладка и продакшен ведут себя по-разному → «раздел Vue».

</details>

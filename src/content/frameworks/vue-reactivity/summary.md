# Реактивность Vue

<details>
<summary><b>Ядро</b> — зависимости создаёт выполнение</summary>

- Чтение реактивного значения во время эффекта создаёт связь с источником. Запись уведомляет подписчиков. После нового запуска остаются только связи, подтверждённые выполненными чтениями. У watch зависимости собирает геттер источника, а не колбэк.

</details>

<details>
<summary><b>Карта</b> — от чтения к обновлению</summary>

- [Модель](/frameworks/vue-reactivity/#s1): Proxy перехватывает операции с объектом; ref предоставляет собственный геттер и сеттер value.
- [Граф](/frameworks/vue-reactivity/#s2): условная ветка detailed определяет, зависит ли эффект от qty. Демо выполняет настоящее @vue/reactivity; отображаемые рёбра фиксируют обёртки чтения.
- [Планировщик](/frameworks/vue-reactivity/#s3): sync выполняется при записи, pre — до патча собственного компонента, post — после. NextTick ждёт текущую очередь Vue.
- [Ловушки](/frameworks/vue-reactivity/#s4): искать потерю контейнера, обход прокси, старую ссылку и отсутствующее реактивное чтение.
- [Жизнь эффекта](/frameworks/vue-reactivity/#s5): синхронные watcher’ы компонента останавливаются с его областью.

</details>

<details>
<summary><b>Подвох</b> — границы удобств</summary>

- Ref рекомендуют для объявления состояния, но деструктуризация value тоже оставляет снимок.
- Ref в массиве не разворачивается при доступе из JS. Итоговый ref текстовой интерполяции разворачивается отдельно при выводе.
- Computed Vue 3.5 не входит в список эффектов области: сохранённую ссылку можно читать после scope.stop.
- Обычный async-колбэк теряет активный контекст после await; верхнеуровневый await в script setup компилятор обрабатывает отдельно.
- KeepAlive скрывает компонент без остановки его render-эффекта и watcher’ов.

</details>

<details>
<summary><b>Детали</b> — замер и диагностика</summary>

- Стоимость Proxy снята отдельно на искусственном цикле Node 26.8.2; отношения из таблицы не предсказывают цену компонента. OnTrack/onTrigger — отладочные хуки. NextTick подтверждает обработку текущих заданий Vue, а не предъявление кадра экрану или бесплатное измерение геометрии.

</details>

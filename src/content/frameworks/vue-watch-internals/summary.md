# Vue 3 изнутри: watch, effectScope и computed 3.5

`frameworks/vue-watch-internals` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** `watch` — эффект с планировщиком и сравнением значений; `effectScope` — список эффектов, которые останавливаются одним `stop`; `computed` 3.5 узнаёт об изменениях по номерам версий.
- **Зачем:** звать колбэк, только если значение правда изменилось; останавливать эффекты пачкой; не пересчитывать цепочку, когда итог прежний.
- **Как работает:**
  1. Источник → геттер → эффект; `scheduler` ставит задание, задание проверяет `isDirty`, перечитывает и сравнивает `Object.is`.
  2. Очистка — перед следующим колбэком и при `stop`.
  3. Новый эффект кладёт себя в `activeScope`; `stop` гасит эффекты, очистки, детей.
  4. `Link` хранит увиденную версию; `computed` поднимает свою, только если значение другое.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Четыре вида источника и `deep` как число чтений → «раздел watch».
- Гонка асинхронных ответов лечится очисткой (флаг `stale` или `abort`) → «раздел onCleanup».
- `flush` — лишь выбор `scheduler`; `watchEffect` против `watch` → «раздел flush».
- Вложенная область останавливается с родителем, отсоединённая — нет; есть `pause`/`resume` → «раздел effectScope».
- Пометка вместо пересчёта, `globalVersion`, пакет `batchDepth` → «раздел computed 3.5».
- Утечка: источник → `Dep` → `Link` → эффект → замыкание → «раздел Утечки».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `watch(() => state.obj)` не видит изменений внутри, а `watch(state)` зовётся на каждое (`forceTrigger`).
- `once` + `onCleanup` отменяют собственный асинхронный запрос.
- `scope.stop()` не трогает `computed`; `effectScope(true)` внутри `run` родителя всё равно ничей.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- `deep: 1` читает только ключи верхнего уровня; число вместо `true` (3.5) → «раздел watch».
- `onWatcherCleanup` работает только до первого `await`; `onCleanup` (третий аргумент колбэка) — и после него → «раздел onCleanup».
- Порядок: `sync` на каждой записи → `pre` → `post` → `nextTick` → «раздел flush».
- `refreshComputed`: `dirty` → `globalVersion` → `isDirty` → пересчёт → «раздел computed 3.5».
- В Vue: `dep.activeLink`, счётчик `sc`, битовые `flags` → «раздел Мини против Vue».

</details>

# React изнутри: хуки и контекст

- React связывает вызовы хуков состояния с ячейками по порядку, а не по имени переменной. Нельзя менять число и порядок таких вызовов между render.
- Состояние и очереди обновлений живут в fiber, а функция компонента читает снимок конкретного render. Замыкание не начинает автоматически видеть будущие значения.
- Зависимости эффекта или memo определяют, когда переиспользовать результат. Они не заменяют идентичность компонента, планирование lanes или подписку на контекст.
- Изменившийся контекст может обновить читателя под memo-компонентом. Пропуск промежуточного вызова и отсутствие работы во всём поддереве — разные утверждения.
- Внешний изменяемый store требует согласованного протокола подписки и снимка. `useSyncExternalStore` помогает не опубликовать смесь состояний при конкурентной работе; эффектам всё равно нужна очистка.

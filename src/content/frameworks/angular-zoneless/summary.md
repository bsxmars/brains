# Angular без zone.js

`frameworks/angular-zoneless` · выжимка обновлена 2026-11-12.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** два способа запрашивать проверку: завершение отслеживаемой работы внутри Angular-зоны и известные Angular уведомления в zoneless.
- **Зачем:** шаблон читает обычные поля, запись в них ничего не сообщает. Зона получает повод для проверки через поддерживаемые API; это не доказательство изменения данных. Объём обхода отдельно ограничивают OnPush и пометки видов.
- **Как работает:**
  1. С зоной: колбэк запоминает зону при планировании; стек и микрозадачи зоны пусты → `onMicrotaskEmpty` → tick от корня.
  2. Без зоны: тик заказывают изменение сигнала, который читал шаблон, обработчик шаблона, markForCheck, AsyncPipe и другие поддерживаемые уведомления.
  3. Заказы до тика сливаются в один тик.
  4. Сигнал помечает свой компонент; клик и `markForCheck` — вид и всех предков.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- В Angular 21 по умолчанию без зоны, даже с загруженным zone.js → «раздел Обычные поля».
- zone.js прячет подмену через `toString`; новые API не подменены → «раздел zone.js».
- `OnPush` режет шаблоны, но не тики; в dev второй проход → «раздел Цена».
- Родной `await` теряет зону, CLI переписывает `async` в генератор → «раздел async/await».
- Тик откладывается на задачу; планировщик работает и при зоне → «раздел Без зоны».
- Читатель сигнала — шаблон компонента целиком, `effect` отложен в проверку → «раздел Сигналы Angular».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Обычное поле может измениться без заказа проверки: экран останется прежним до следующей подходящей проверки. Используйте уведомляющий сигнал или markForCheck.
- С зоной и родным `await` запись после `await` может не попасть на экран: тик прошёл до продолжения.
- `items().push` внутри сигнала не замечается — нужен новый объект.

</details>

<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- 10 × `mousemove` с зоной = 10 тиков; `NG0100` → «раздел Цена».
- `isZonelessApp(polyfills)`, `'async-await': false` → «раздел async/await».
- `scheduleCallbackWithRafRace`: гонка `setTimeout` и `requestAnimationFrame` → «раздел Без зоны».

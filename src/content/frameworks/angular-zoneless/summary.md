# Angular без zone.js

`frameworks/angular-zoneless` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** переход от «проверять дерево после любой асинхронной задачи» (zone.js) к «проверять, когда сказали, что данные изменились».
- **Зачем:** шаблон читает обычные поля, запись в них ничего не сообщает. Зона угадывает момент подменой асинхронных API, но проверяет от корня и впустую.
- **Как работает:**
  1. С зоной: колбэк запоминает зону при планировании; стек и микрозадачи зоны пусты → `onMicrotaskEmpty` → tick от корня.
  2. Без зоны: тик заказывают сигнал, обработчик из шаблона, `markForCheck`, новое `input`.
  3. Заказы до тика сливаются в один тик.
  4. Сигнал помечает свой компонент; клик и `markForCheck` — вид и всех предков.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- В Angular 21 по умолчанию без зоны, даже с загруженным zone.js → «раздел Обычные поля».
- zone.js прячет подмену через `toString`; новые API не подменены → «раздел zone.js».
- `OnPush` режет шаблоны, но не тики; в dev второй проход → «раздел Цена».
- Родной `await` теряет зону, CLI переписывает `async` в генератор → «раздел async/await».
- Тик откладывается на задачу; планировщик работает и при зоне → «раздел Без зоны».
- Читатель сигнала — шаблон компонента целиком, `effect` отложен в проверку → «раздел Сигналы Angular».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Без зоны запись в обычное поле из таймера/`fetch` не видна — ошибки нет, экран старый. Лечение: сигнал или `markForCheck()`.
- С зоной и родным `await` запись после `await` может не попасть на экран: тик прошёл до продолжения.
- `items().push` внутри сигнала не замечается — нужен новый объект.

</details>

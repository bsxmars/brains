# Angular без zone.js

- Повод проверить шаблоны и объём самой проверки — разные вещи. Zone.js помогает Angular узнать о завершении отслеживаемой асинхронной работы, но не доказывает изменение данных.
- В zoneless Angular планирует проверку по известным уведомлениям: изменению прочитанного шаблоном сигнала, обработчику шаблона, markForCheck, AsyncPipe и другим поддерживаемым механизмам.
- Обычная запись в поле сама по себе не является универсальным уведомлением. Если экран не обновился, сначала проверьте, каким способом Angular должен узнать об изменении.
- OnPush и пометки видов ограничивают обход. Сам факт запланированного tick не означает одинакового повторного выполнения всех шаблонов.
- Несколько уведомлений могут объединиться в одну проверку. Для интеграции с внешним кодом нужны корректное уведомление, область жизни подписки и очистка; отказ от зоны не отменяет эти задачи.

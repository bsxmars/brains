# Формы во фреймворках: где живёт значение поля

`frameworks/forms` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** значение поля всегда лежит в DOM (`input.value`); контролируемое поле держит вторую копию в состоянии фреймворка.
- **Зачем:** копия нужна для превью, масок, зависимых полей; странности форм — на стыке копий.
- **Как работает:**
  1. Браузер вставляет символ сам → `input` → обработчик пишет в состояние.
  2. Рендер отдаёт полю `value`; совпало с DOM — запись пропускается.
  3. Не совпало — запись в `input.value`, для браузера это замена текста: каретка в конец.
  4. Неконтролируемое поле: `defaultValue`, значение читают через `ref` или `FormData`.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Поле без `onChange` замерзает → «раздел Две копии».
- `v-model` на элементе — директива под тип поля, на компоненте — проп и событие → «раздел v-model».
- Рендеры на символ зависят от места состояния → «раздел Цена символа».
- Возврат каретки: запомнить `selectionStart`, вернуть после записи → «раздел Каретка».
- `v-model` ждёт `compositionend`, React — нет → «раздел IME».
- Встроенная проверка и `:user-invalid` → «раздел Валидация».
- `FormData` и действия формы React 19 → «раздел Отправка».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Любое преобразование или асинхронный `setState` уносит каретку в конец.
- Фильтр в сеттере `v-model` оставляет букву: модель та же, рендера нет.
- После `action` React 19 неконтролируемые поля сбрасываются к `defaultValue`, даже при ошибке.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- `vModelText`/`Checkbox`/`Radio`/`Select`; `.lazy`, `.trim`, `.number` → «раздел v-model».
- Состояние в форме: 6 рендеров, на 20 полях — 22; `memo` + `useCallback` — 3; в DOM — 0 → «раздел Цена символа».
- Пять `onChange` с `isComposing` на слово → «раздел IME».
- `reportValidity`, `setCustomValidity('')`, `novalidate` → «раздел Валидация».
- `useActionState`, `useFormStatus`; `Object.fromEntries` оставляет последний ключ → «раздел Отправка».

</details>

# Формы во фреймворках: где живёт значение поля

- У поля всегда есть текущее значение в DOM. Контролируемая форма держит ещё одну копию в состоянии фреймворка и возвращает её полю при обновлении.
- При вводе браузер сначала меняет поле, затем вызывает обработчик. Обработчик должен согласовать состояние с вводом; запоздавшая или преобразованная копия может перезаписать значение.
- Запись input.value — замена текста, которая способна изменить выделение и положение каретки. Для масок и форматирования сохраняйте осмысленную позицию, учитывая IME.
- Неконтролируемая форма оставляет текущее значение браузеру; его можно прочитать через ref или FormData. `defaultValue` задаёт начальное значение, а не постоянную синхронизацию.
- Выбирайте одну понятную модель владения значением. Проверка на клиенте улучшает ввод, но сервер всё равно должен проверить данные; программные изменения и сброс формы требуют отдельной обработки.

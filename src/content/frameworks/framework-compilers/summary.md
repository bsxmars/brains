# Компиляторы фреймворков

<details>
<summary><b>Ядро</b> — что сборка может знать заранее</summary>

- Компилятор читает код компонента и генерирует проверки кеша или привязки изменчивых мест к DOM. Он знает возможные зависимости, но будущие значения узнаёт рантайм. Проверка равенства, выполнение реактивных чтений и изменение DOM остаются при исполнении.

</details>

<details>
<summary><b>Карта</b> — разные результаты компиляции</summary>

- [Учебный компилятор](/frameworks/framework-compilers/#s2): разбор шаблона → имена зависимостей → клон HTML и update для найденных узлов.
- [React Compiler](/frameworks/framework-compilers/#s3): Counter вызывается снова; независимый Hint в примере берётся из кеша как прежний объект элемента.
- [Отказы](/frameworks/framework-compilers/#s4): диагностика нарушений правил React, logger, panicThreshold и директива use no memo.
- [Svelte 5](/frameworks/framework-compilers/#s5): руны становятся вызовами реактивного рантайма, шаблон — HTML и эффектами привязок.
- [Solid](/frameworks/framework-compilers/#s6): JSX превращается в template и insert; функция компонента на клике не вызывается заново.

</details>

<details>
<summary><b>Подвох</b> — границы оптимизации</summary>

- Мутация массива с сохранением ссылки может оставить кешированный вывод устаревшим. Правила неизменяемости React остаются обязательными.
- В разобранном Cart результат sum(items), используемый только в арифметике, не получил кеш; это наблюдение о конкретном выводе компилятора, а не запрет мемоизации чисел.
- Чтение Svelte state в обычную переменную не заменяет derived. Деструктуризация реактивных пропсов Solid может оставить снимок.

</details>

<details>
<summary><b>Детали</b> — что измеряет сравнение</summary>

- [Один клик](/frameworks/framework-compilers/#s7) сравнивает один компонент, собранный зафиксированными версиями. Счётчики снимаются в happy-dom: вызовы Counter/Hint и записи MutationObserver типа characterData. Это не время браузерного кадра и не рейтинг скорости фреймворков. В примере компиляторы прежде всего сокращают работу JS до DOM; React без компилятора тоже записывает только изменившийся текст.

- Литералы вывода React Compiler 1.0.0, Svelte 5.57.1 и Solid 1.9.15 сверяются тестом с настоящими компиляторами. Интерактивный редактор исполняет учебный компилятор.

</details>

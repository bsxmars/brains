# Компиляторы фреймворков

`frameworks/framework-compilers` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** программа, которая при сборке переписывает компонент в другой JS, заранее выяснив, что от чего зависит.
- **Зачем:** перенести работу из браузера в сборку; цена — строже язык компонента: оптимизируется только то, что компилятор понял.
- **Как работает:** разбор шаблона → анализ зависимостей каждого изменчивого места → генерация: статика в одну строку HTML (клонируется), изменчивое — в список «изменилось X → обнови узел Y». Проверка «значение то же» остаётся в рантайме.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Спектр: React без компилятора → React Compiler / Vue-шаблоны → Svelte, Solid, Vapor → «Где делается работа».
- React Compiler: компонент всё равно вызывается, неизменённое берётся из кеша; тот же объект элемента — ребёнок не вызывается → «React Compiler».
- Отказы при нарушении правил React, по умолчанию молча → «Отказы».
- Svelte: руны → вызовы рантайма, один эффект на шаблон, объект в `$state` → прокси → «Svelte 5».
- Solid: JSX → `template` + `insert` на каждое выражение, функция компонента выполняется раз → «Solid».
- Записей в DOM почти поровну; экономится работа до них → «Одно изменение».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Мутация на месте (`items.sort()`, `push` в тот же массив) компилируется, и мемоизация прячет изменение — список не обновляется.
- Дорогой расчёт, ушедший только в арифметику, не мемоизируется; ручной `useMemo` вокруг него компилятор убирает.
- Svelte без `$derived` читает значение один раз; Solid: деструктуризация пропсов обрывает реактивность.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- `_c(n)` = `useMemoCache`, пустая ячейка — `Symbol.for("react.memo_cache_sentinel")` → «React Compiler».
- Категории отказов: `Hooks`, `Immutability`, `Refs`, `RenderSetState`, `Globals`; видны через `logger`, ESLint; `panicThreshold`; выход — `'use no memo'` → «Отказы».
- `$.state`/`$.get`/`$.update`, `$.from_html`, `$.template_effect` + `$.set_text`, `$.proxy`, предупреждение `state_referenced_locally` → «Svelte 5».
- Клик «+1»: вызовов `Counter` 1/1/0/0, `Hint` 1/0/0/0 (React, React+Compiler, Svelte, Solid); записей 2, у Svelte 1 → «Одно изменение».

</details>

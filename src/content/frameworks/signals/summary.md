# Сигналы: третья модель реактивности

<details>
<summary><b>Ядро</b> — значение и его читатели</summary>

- Сигнал связывается с вычислением во время чтения. В учебной push-pull реализации запись сначала меняет значение и помечает весь зависимый граф, затем запускает очередь эффектов. Производный сигнал пересчитывается при чтении; версия растёт только при изменении результата. Это позволяет остановить лишний пересчёт дальше по цепочке.

</details>

<details>
<summary><b>Карта</b> — от ячейки к DOM</summary>

- [Сигнал](/frameworks/signals/#s1): значение, версия, подписчики и обратные связи.
- [Push и pull](/frameworks/signals/#s2): пометка вниз и проверка источников при чтении.
- [Ромб](/frameworks/signals/#s3): наивный push видит [4, 2], согласованный эффект — [4, 3].
- [Эффект и пакет](/frameworks/signals/#s4): очередь запускается после пометки или внешнего batch.
- [DOM](/frameworks/signals/#s5): эффект хранит адрес изменчивого узла; в мини-рендерере нет сравнения деревьев.
- [Vue и React](/frameworks/signals/#s6): реактивность и единица обновления интерфейса — разные решения.

</details>

<details>
<summary><b>Подвох</b> — что откладывается</summary>

- Batch откладывает эффекты, а не записи: явное чтение внутри пакета уже видит новые значения.
- Сигнал хранит ссылку. Мутация объекта без set не проходит сравнение и не уведомляет читателей; Vue ref по умолчанию оборачивает объект глубоко.
- В мини-версии вложенные эффекты требуют собственной остановки; они не уничтожаются при перезапуске внешнего.
- Чтение вне вычисления не создаёт подписку.

</details>

<details>
<summary><b>Детали</b> — границы реализаций</summary>

- [Сверка библиотек](/frameworks/signals/#s8) относится к конкретным сценариям и версиям Vue 3.5.42 и alien-signals 3.2.1. Демо исполняет учебную реализацию. У публичного @vue/reactivity нет синхронного batch.

- [Предложение TC39](/frameworks/signals/#s7) остаётся Stage 1 по README на 2026-11-12. Watcher уведомляет синхронно после пометки графа и запрещает чтение/запись сигналов из notify; расписание эффектов остаётся фреймворку. Это описание проекта API, а не встроенный Signal в браузере.

</details>

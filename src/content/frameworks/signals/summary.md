# Сигналы: третья модель реактивности

- Сигнал хранит значение и связывается с активным вычислением во время чтения. Для создания зависимости нужно само чтение, а не просто ссылка на сигнал.
- Производное значение описывает расчёт из других сигналов. Эффект нужен для побочного действия; смешивание этих ролей делает порядок работы и циклы зависимостей сложнее.
- В показанной push-pull модели запись сначала помечает зависимый граф. Производные значения пересчитываются при необходимости, а версии результата помогают остановить лишнюю работу дальше по цепочке.
- Зависимости меняются вместе с ветками выполнения: после повторного вычисления должны остаться только действительно прочитанные источники. Пропущенная очистка оставляет лишние подписки.
- Пакетирование объединяет запуски эффектов, но не отменяет правила чтения и сравнения. Планирование, равенство и очистка отличаются между библиотеками; сигнал сам по себе не гарантирует определённую работу DOM.

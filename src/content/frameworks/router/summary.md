# Роутер изнутри: от адреса до экрана

`frameworks/router` · выжимка обновлена 2026-11-12.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** связь адреса и экрана SPA в обе стороны без загрузки документа.
- **Зачем:** документ один на сессию, а адрес должен работать как настоящий: копироваться, «назад», новая вкладка.
- **Как работает:** для router.push: находит цель и matched → выполняет нужные guards и загрузку кода → подтверждает маршрут и меняет запись истории → Vue обновляет экран. При popstate адрес уже изменён браузером, поэтому отмена восстанавливает историю.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- `pushState` молчит, `popstate` — только на ход по истории и смену якоря → раздел «История вкладки».
- Одно событие `navigate` на все переходы, браузер сам говорит, можно ли перехватить → раздел «Navigation API».
- Забирать клик, только если браузер сменил бы документ в этой вкладке на свой сайт; переход — ссылка, не `div @click` → раздел «Перехват клика».
- Порядок в массиве не важен: сортировка по весу, при равенстве — по объявлению → раздел «Ранжирование».
- `children` → плоский список; ребёнок с пустым путём встаёт перед родителем → раздел «Вложенные маршруты».
- Зависимые загрузки вложенных компонентов могут создать водопад; общая загрузка независимых данных до или параллельно переходу уменьшает ожидание → раздел «Ленивые маршруты и данные».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Обычная отмена guard не бросает из push — проверяйте isNavigationFailure. Исключение внутри guard — другой исход, его нельзя считать успешной отменой.
- `return Promise.all(…)` из guard: массив = адрес, переход молча становится «уже здесь».
- При повторном использовании тех же записей маршрута смена `:id` не вызывает beforeEnter; для обновления предназначен beforeRouteUpdate.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Веса: текст 80, параметр 60, своя регулярка 70, `?` −8, `+`/`*` −20, `.*` −50 → раздел «Шаблон пути».

</details>

# Интернационализация: ICU MessageFormat и словари

`frameworks/i18n` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** фраза с числом или именем — маленькая программа с ветками по числу, роду, порядковому номеру; ICU MessageFormat — язык таких сообщений.
- **Зачем:** склейка строк в коде решает за переводчика порядок слов и форму слова — и ошибается («Удалить 1 файлов»).
- **Как работает:** код передаёт ключ и значения → сообщение разбирается в дерево → `select`/`plural` выбирают ветку (`=N`, потом категория CLDR, потом `other`) → строка собирается.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Ломаются порядок слов, число, род, падеж → «Склейка».
- `select`, `plural` с `#`, `=N`, `offset`, `selectordinal`, апострофы, `number` → «Синтаксис ICU».
- Рекурсивный спуск `parse` → `pick` → `format` → «Свой парсер».
- Разбор при сборке убирает парсер из бандла и переносит ошибки перевода в сборку → «Сборка».
- MF2: ветвление наверху через `.match`; в браузерах нет, исполняет пакет `messageformat` 4 → «MessageFormat 2».
- vue-i18n: свой формат (не ICU), ленивые словари, цепочка запасных локалей, локаль — `ref` → «vue-i18n».
- Источники локали: путь, cookie, `Accept-Language`, `navigator.languages`; `hreflang`, RTL → «Выбор локали».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- vue-i18n по умолчанию — «ноль | один | много», для русского неверно без `pluralRules`; `@` в тексте — ошибка компиляции.
- Апостроф перед `{` открывает цитату и съедает аргумент; `{n}` без `number` не локализуется.
- Явная запасная локаль заменяет неявную обрезку; обрезка `zh-Hant-TW` → `zh` меняет письменность. Локаль выбирают один раз на сервере — иначе гидратация расходится.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Русские категории: `one`, `few`, `many`, `other`; дробь — `other`; у арабского шесть → «Синтаксис ICU».
- `intl-messageformat` без парсера (`no-parser.js`), `compileModule`; `compile` зовёт `new Function` — конфликт с CSP → «Сборка».
- `messageCompiler` для ICU — кешировать самому; словарь грузить до смены `locale` → «vue-i18n».
- Порядок решает `q`; `Vary: Accept-Language`; `x-default`; `getTextInfo().direction`, `margin-inline-start`, `<bdi>` → «Выбор локали».

</details>

    Перевод интерфейса — не замена слов. Фраза с числом или именем внутри — это маленькая
    программа: в ней есть ветки по числу, роду, порядковому номеру. Переводчик пишет все
    ветки целиком на своём языке, а код только передаёт значения и получает готовую строку.

  </Callout>

  Код, который собирает фразу сам — `'Удалить ' + n + ' файлов'`, — решает за переводчика,
  в каком порядке идут слова и какая у слова форма. Для английского такое решение обычно
  верно. Для русского оно ошибается на «1 файлов», для японского — на порядке слов. ICU
  MessageFormat — общий язык таких сообщений: его понимают библиотеки, сервисы перевода
  и сами переводчики.

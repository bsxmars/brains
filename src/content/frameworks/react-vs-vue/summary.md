# React против Vue

- Вызов функции компонента, вычисление результата и изменение DOM — разные виды работы. Измерение только одного из них не объясняет стоимость обновления.
- React планирует работу по дереву компонентов. Обновление состояния отмечает нужную часть дерева; стабильные элементы и memo позволяют пропустить подходящие участки.
- Vue связывает реактивные чтения с эффектами и уведомляет их при записи. Компилятор дополнительно выделяет изменчивые места шаблона, чтобы renderer проверял меньше.
- Обе модели могут выполнить код и оставить DOM прежним, если итоговые значения совпали. Стабильность данных и границы подписок важнее лозунга о «полном» или «точечном» рендере.
- Для сравнения задайте одинаковое действие и отдельно считайте вызовы компонентов, пересчёты и записи в DOM. Время браузерного layout и paint требует собственного измерения.

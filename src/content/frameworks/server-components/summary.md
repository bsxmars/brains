# Server Components изнутри

- React Server Components оставляют исполнение части компонентов на сервере. SSR отвечает за первоначальный HTML; эти механизмы решают разные задачи и могут работать вместе.
- Результат серверного дерева передаётся протоколом Flight вместе со ссылками на клиентские модули. Код серверного компонента не обязан попадать в клиентский bundle.
- Граница use client определяет клиентскую часть графа модулей. Через неё передают только поддерживаемые значения; произвольная функция или экземпляр класса не становятся передаваемыми автоматически.
- Клиентские компоненты нужны для состояния и взаимодействия с браузером. Серверный результат можно передать им как часть дерева без превращения всего исходного модуля в клиентский.
- Серверная функция вызывается через специальный протокол и остаётся внешней точкой входа. Проверка прав, входных данных и побочных эффектов нужна при каждом вызове, независимо от того, откуда отрисована кнопка.

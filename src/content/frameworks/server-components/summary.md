# Server Components изнутри

`frameworks/server-components` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** компоненты, которые исполняются только на сервере и присылают не HTML и не код, а результат — дерево элементов текстовым потоком Flight.
- **Зачем:** не везти в браузер код, нужный лишь для вычисления результата; гидратируются только клиентские компоненты.
- **Как работает:**
  1. Сериализатор обходит дерево: серверный компонент вызывается на месте, клиентский становится ссылкой на модуль (I-строка).
  2. Всё, чего нет в JSON, кодируется строками с префиксом `$`.
  3. `async`-компонент оставляет дыру `$L`, строка досылается по готовности.
  4. Клиент подставляет пришедшее по ссылкам; SSR может отрендерить HTML из того же потока.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Не замена SSR, а другой вид компонента; серверная сборка React без хуков состояния → «раздел Не другой SSR».
- Строки потока, префиксы, порядок внутри куска → «раздел Формат потока».
- Через границу проходят данные; функции, классы, локальные символы — ошибка → «раздел Граница 'use client'».
- Серверная функция приезжает id, вызов — `callServer` → «раздел Серверные функции».
- Сервер ждёт промисы, клиент — на границах Suspense; `cache()` — на один рендер → «раздел Async, Suspense, cache».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Недопустимый проп не валит рендер: E-строка в потоке, падает весь элемент у клиента. Даже `onClick` на `<button>` серверного компонента.
- `bind` кладёт аргументы в поток открытым текстом; две ссылки на одну функцию — разные функции.
- `cache()` вне рендера не кеширует, аргументы сравниваются по ссылке. `$L` не всегда значит `async`.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Элемент — кортеж `["$", тип, ключ, пропсы]`; номера шестнадцатеричные → «раздел Формат потока».
- `$L`, `$@`, `$h`, `$S`, `$D`, `$Q`/`$W`, `$Z`, `$$` → «раздел Формат потока».
- `T` от 1024 символов; нарезка модели после ~3200 → «раздел Своими руками».
- Условие экспорта `react-server`; `useState` там — `TypeError` → «раздел Не другой SSR».
- В продакшене только `digest` → «раздел Тонкие места».

</details>

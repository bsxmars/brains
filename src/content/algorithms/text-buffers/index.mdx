  <Callout size={19} pad="24px 26px">

    Дорого не хранить текст, а **переписывать** его. Одна строка переписывает весь документ
    на каждую букву. Gap buffer переписывает только то, что между старым и новым местом
    курсора, rope — один короткий кусок, piece table — вообще ничего, кроме нового текста.

  </Callout>

  Поле ввода хранит текст одной строкой, и этого хватает: в нём сотни символов. Редактор
  кода держит файлы на мегабайты, правит их на каждое нажатие клавиши и сотни раз в секунду
  спрашивает «где начинается строка 1200» — для отрисовки, подсветки и ошибок. Если на каждую
  букву переписывать весь файл, редактор начнёт отставать от пальцев. Структуры, которыми
  это решают, придуманы десятки лет назад и стоят в Emacs, VS Code и совместных редакторах.

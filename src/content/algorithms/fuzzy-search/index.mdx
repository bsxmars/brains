    Нечёткий поиск решает две разные задачи. Первая — **найти** кандидатов, не сравнивая
    запрос с каждой строкой: для этого слова раскладывают в дерево. Вторая — **упорядочить**
    найденное, и здесь расстояние между словами — только одно из слагаемых.

  </Callout>

  Строка поиска есть почти в каждом интерфейсе: меню команд, список городов, каталог
  товаров, документация. Люди печатают начало слова, ошибаются в буквах и сокращают как
  придётся. `filter` с `includes` не прощает ни одной опечатки, а библиотека прощает
  столько, что в выдаче оказывается мусор. Чтобы настроить её осознанно, полезно один раз
  собрать всё руками.

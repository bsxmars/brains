# Diff: как git и фреймворки находят разницу

- Diff сравнивает две последовательности при заданных операциях и их цене. Сравнение строк файла, перенос DOM-узла и слияние правок — разные задачи.
- Для модели «удалить или вставить» общая подпоследовательность остаётся нетронутой. Чем она длиннее, тем короче скрипт изменений; Майерс ищет кратчайший путь через совпадения и правки.
- Кратчайший скрипт не обязательно удобен человеку. Git использует разные алгоритмы и эвристики границ, чтобы изменения было легче читать на ревью.
- В списке уникальные устойчивые ключи связывают старые и новые элементы. Для перестановки совместимых узлов LIS определяет, кого можно оставить на месте; Vue и React выбирают перемещения по-разному.
- Добавление нового первого элемента не равно переносу старого последнего. Считайте отдельно создание, удаление и перемещение; ключ из индекса массива может скрыть изменение идентичности элемента.

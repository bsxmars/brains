# Кеш перед базой: Redis, инвалидация и толпа

`data/redis-cache` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** кеш — копия с договором: сколько отстаёт, сколько запросов пускать в базу, когда пуст, что выбросить, когда полон.
- **Зачем:** Redis отвечает за доли миллисекунды, но не знает, что база поменялась.
- **Как работает:** cache-aside. Читатель при промахе читает базу и кладёт ключ с TTL. Писатель после `COMMIT` удаляет ключ, а не перезаписывает. TTL — верхняя граница вранья.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Схемы: cache-aside, read-through, write-through, write-behind → «раздел Cache-aside».
- Обычный `SET` стирает срок; истёкшее удаляется лениво и фоном → «раздел Срок ключа».
- Гонки: медленный читатель, удаление до `COMMIT`, реплика → «раздел Гонка инвалидации».
- Аренда `SET NX`, версия, двойное удаление; проверка с записью — одной функцией Lua → «раздел Чем лечить гонку».
- Толпа: замок, XFetch, мягкий срок → «раздел Толпа».
- `maxmemory-policy`, приближённый LRU по выборке → «раздел Вытеснение».
- После рестарта — толпа по всем ключам; RDB, прогрев → «раздел Холодный кеш».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Реплику не ловят ни «`DEL` после `COMMIT`», ни аренда — только версия.
- Замок снимать по токену: простой `DEL` снимает чужой. Взяв замок — перечитать кеш.
- `allkeys-lru` выбрасывает сессии без срока, `volatile-ttl` — горячие; XFetch бессилен на пустом ключе.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- `TTL`: `-1` — без срока, `-2` — нет ключа; `KEEPTTL` → «раздел Срок ключа».
- 50 читателей: без защиты 50 походов в базу, с замком 1 → «раздел Толпа».
- По умолчанию `noeviction` (`OOM`), выборка 5, пул 16 → «раздел Вытеснение».
- Выборка 1 — LRU становится случайным → «раздел Вытеснение».
- `docker kill` теряет записанное после снимка → «раздел Холодный кеш».
- Аренды — Facebook, 2013 → «раздел Чем лечить гонку».

</details>

# Безопасность фронтенда

- Same-Origin Policy ограничивает чтение чужих данных. CORS может разрешить чтение ответа определённому origin, но его отказ не откатывает запрос, который сервер уже обработал.
- Авторизация проверяется сервером для каждой операции и объекта. Скрытая кнопка, клиентский роутер и заголовок, который может подставить вызывающий, не заменяют проверку прав.
- XSS запускает чужой код в контексте сайта. Экранируйте данные по месту вставки, избегайте опасных HTML-sink и используйте CSP как дополнительное ограничение исполнения.
- CSRF использует автоматически отправляемые полномочия браузера. Сервер должен проверять допустимость и намерение запроса; SameSite, токены, Origin и Fetch Metadata имеют разные границы.
- HttpOnly закрывает значение cookie от JS API, но внедрённый код всё ещё может действовать от имени пользователя. Безопасность складывается из независимых ограничений, а не одного «защитного» заголовка.

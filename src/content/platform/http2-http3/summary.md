# HTTP/2 и HTTP/3

`platform/http2-http3` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** новые способы везти тот же HTTP по проводу: HTTP/2 режет запросы на пронумерованные кадры в одном TCP-соединении, HTTP/3 делает то же поверх QUIC.
- **Зачем:** HTTP/1.1 везёт один запрос за раз и держит шесть соединений на источник; HTTP/2 убрал очередь запросов, HTTP/3 — зависимость всех потоков от одной ленты байтов TCP.
- **Как работает:**
  - Кадр: 9 байт заголовка (длина, тип, флаги, номер потока), потоки идут вперемешку.
  - Окно приёма у каждого потока и у соединения; пополняет WINDOW_UPDATE.
  - HPACK: статическая и динамическая таблицы, повторный заголовок — номером.
  - В QUIC потоки — часть транспорта: потеря пакета задерживает только свой поток.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Двадцать `fetch`: 6 соединений по HTTP/1.1 против одного по HTTP/2 → «раздел Шесть соединений и одно».
- Типы кадров, нечётные потоки у клиента, SETTINGS браузеров, RST_STREAM/GOAWAY/PING → «раздел Кадры».
- Отправитель шлёт DATA, только если место есть в обоих окнах → «раздел Потоки и окно».
- Целые с префиксом, Хаффман, литерал «никогда не запоминать» против CRIME → «раздел HPACK».
- TCP по-прежнему тормозит все потоки; server push умер, его заменил `103 Early Hints`; приоритеты — заголовок `priority` → «раздел Пределы HTTP/2».
- 1-RTT и 0-RTT, миграция по ID соединения, QPACK, `Alt-Svc` и DNS-запись `HTTPS` → «раздел HTTP/3 и QUIC».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Пропущенный блок HPACK не даёт ошибки: номера съезжают, декодер выдаёт чужие заголовки.
- 0-RTT повторяем: неидемпотентное не принимать (`Early-Data: 1`, `425 Too Early`).
- HTTP/3 не ускоряет первый визит без DNS-записи `HTTPS`; неудача QUIC молча откатывается на TCP — проверять по `nextHopProtocol`.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Приветствие клиента — 24 байта `PRI * HTTP/2.0…`; окно по умолчанию 65 535, таблица 4096 → «раздел Кадры».
- `user-agent`: 99 байт в первом запросе, 1 байт дальше; `:path` всегда литералом → «раздел HPACK».
- Запись таблицы весит имя + значение + 32 байта; новая встаёт под номер 62 → «раздел HPACK».
- Первый пакет QUIC не меньше 1200 байт; ответ сервера не больше чем втрое → «раздел HTTP/3 и QUIC».
- QPACK: статическая таблица на 99 записей, отдельные потоки кодировщика и декодера → «раздел HTTP/3 и QUIC».

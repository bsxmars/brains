# Стримы и обратное давление

`platform/streams` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** Web Stream — очередь с порогом плюс правило «источник наполняет очередь, только когда его просят».
- **Зачем:** `res.text()` ждёт и держит тело целиком; стрим даёт обрабатывать по частям, а медленный потребитель сам замедляет источник до сервера.
- **Как работает:**
  - Три числа: `highWaterMark` (порог), `queueTotalSize`, `desiredSize = HWM − очередь` (бывает отрицательным).
  - Пока `desiredSize > 0`, платформа зовёт `pull`; места нет — перестаёт звать. Обратное давление — отсутствие вызова, а не сигнал.
  - На записи давление чувствуется только через `await writer.ready`.
  - Трансформ получает чанки по одному и хранит состояние между ними в замыкании.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Источник, который шлёт сам (сокет), обратным давлением не остановить — решать по `desiredSize` → «раздел Три числа».
- `start`/`pull`/`cancel`; `enqueue`, `close`, `error` у контроллера → «раздел Читаемый поток».
- `ready` против `write`, стратегии очереди, `node:stream` с `drain` и `pipeline()` → «раздел Записываемый и HWM».
- `pipeThrough` без скрытых буферов; разбор SSE и NDJSON, `Last-Event-ID` → «раздел Трансформация».
- `cancel` против `abort`, цена `tee`, один читатель → «раздел Отмена, tee и блокировка».
- `for await` отменяет стрим на `break`; BYOB отсоединяет буфер → «раздел Итерация и байты».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `TextDecoder` без `{ stream: true }` рвёт кириллицу на границе чанка; `\r` на конце чанка ломает наивный SSE-разбор.
- `flush` зовут только при штатном закрытии; без него последнее событие исчезает молча.
- После `cancel` цикл видит `done: true` и не отличит «стоп» от конца — для этого нужен `abort`. `tee` и `response.clone()` копят медленную ветку целиком.

</details>

<summary><b>Детали</b> — не учить, смотреть в теме</summary>

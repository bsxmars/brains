# Стримы и обратное давление

`platform/streams` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** Web Stream передаёт чанки через очередь с порогом; pull-источник вызывается по спросу, push-источник требует отдельного управления.
- **Зачем:** `res.text()` ждёт и держит тело целиком; стрим даёт обрабатывать по частям, а медленный потребитель передаёт обратное давление сотрудничающим звеньям. Прокси может буферизовать ответ.
- **Как работает:**
  - Три числа: `highWaterMark` (порог), `queueTotalSize`, `desiredSize = HWM − очередь` (бывает отрицательным).
  - Платформа зовёт pull для ожидающего read или пополнения запаса до порога; при HWM 0 чанк может сразу уйти читателю без очереди.
  - `writer.ready` сообщает о спаде давления, а промис `write()` — о завершении конкретной записи.
  - Трансформ получает чанки по одному и хранит состояние между ними в замыкании.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Push-источник поток автоматически не остановит — решать по `desiredSize` → «раздел Три числа».
- `start`/`pull`/`cancel`; `enqueue`, `close`, `error` у контроллера → «раздел Читаемый поток».
- `ready` против `write`, стратегии очереди, `node:stream` с `drain` и `pipeline()` → «раздел Записываемый и HWM».
- `pipeThrough` с отдельными очередями и чанками в работе; разбор SSE и NDJSON, `Last-Event-ID` → «раздел Трансформация».
- `cancel` против `abort`, цена `tee`, один читатель → «раздел Отмена, tee и блокировка».
- `for await` отменяет стрим на `break`; BYOB отсоединяет буфер → «раздел Итерация и байты».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `TextDecoder` без `{ stream: true }` рвёт кириллицу на границе чанка; `\r` на конце чанка ломает наивный SSE-разбор.
- `flush` зовут только при штатном закрытии. Учебный SSE-разборщик отдаёт незавершённое последнее событие при dispatchTail=true; EventSource его отбрасывает.
- После `cancel` цикл видит `done: true` и не отличит «стоп» от конца — для этого нужен `abort`. `tee` и `response.clone()` копят медленную ветку целиком.

</details>

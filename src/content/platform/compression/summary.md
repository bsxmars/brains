# Сжатие в вебе

`platform/compression` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** договор на каждый запрос: браузер перечисляет в `Accept-Encoding`, что умеет распаковать, сервер выбирает одно и пишет в `Content-Encoding`, плюс `Vary: Accept-Encoding`.
- **Зачем:** меньше байт ценой процессора; но у адреса появляется несколько вариантов байтов — это касается кеша, длины, докачки и безопасности.
- **Как работает:**
  - Выбор по весам `q` (RFC 9110): самый тяжёлый годный вариант; `identity` годен, пока не запрещён.
  - Тяжёлое сжатие — заранее, один раз (`.br`, `.gz` рядом с файлом); на лету — лёгкое и только для текста.
  - Словари: новая версия сжимается относительно старой из кеша, по сети едет почти только разница.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Chromium по обычному `http://` просит только gzip; с `Range` — без сжатия; свой `Accept-Encoding` из JS не уйдёт → «раздел Договор заголовков».
- Настоящие серверы выбирают с упрощениями: подстрока, порядок в списке → «раздел Выбор по весам».
- Высокие уровни — только при предсжатии; картинки, шрифты и крошечные файлы не сжимают → «раздел Заранее или на лету».
- `Content-Length` и `Range` считают байты выбранного варианта; у каждого варианта свой `ETag` → «раздел Длина и Range».
- Compression Dictionary Transport: только HTTPS, хеш словаря сверяется → «раздел Словари».
- Длина сжатого ответа выдаёт секрет рядом с отражённым вводом → «раздел BREACH».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Первое в списке — не самое желанное: у Chromium веса равны, и h3 отдал gzip вместо меньшего brotli.
- Без `Vary` общий кеш раздаёт чужой вариант; двойное сжатие и короткий `Content-Length` проходят молча — мусор или обрезанный скрипт.
- HTTPS не прячет длину: ответ с секретом и вводом пользователя не сжимать или маскировать секрет.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Chromium шлёт `gzip, deflate, br, zstd`; со словарём добавляет `dcb, dcz` → «раздел Договор заголовков».
- gzip выше 6 почти ничего не даёт; скачки brotli на 5 и 10–11 → «раздел Заранее или на лету».
- Словарь из прошлой версии: 133 байта вместо ~10,5 тыс. у brotli 11 → «раздел Словари».
- Заголовки: `Use-As-Dictionary`, `Available-Dictionary`, `Dictionary-ID`; brotli со словарём в Node молча не работает → «раздел Словари».
- BREACH: токен из 8 знаков за 128 запросов → «раздел BREACH».

</details>

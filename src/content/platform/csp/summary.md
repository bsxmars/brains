# CSP и Trusted Types

<details>
<summary><b>Ядро</b> — явно назначить доверенный путь</summary>

- CSP выбирает директиву по способу запуска скрипта; при отсутствии берёт fallback. Несколько политик проверяются независимо: пройти нужно каждую.
- Nonce или хеш разрешает начальный скрипт. strict-dynamic позволяет скрипты, созданные работающим кодом; self и хосты не заменяют nonce у тега, вставленного парсером.
- Trusted Types проверяют тип значения в защищённом месте вставки. Без default обычная строка в innerHTML отклоняется; TrustedHTML создаёт разрешённая политика приложения.
- TrustedHTML не доказывает очистку ввода: функция политики должна экранировать, очищать или отклонять данные по правилам приложения.

</details>

<details>
<summary><b>Подвох</b> — проверка может защищать другую границу</summary>

- Динамические пробы в стенде запускает внешний драйвер, уже исполняющий код в обход начального CSP. Их успех не доказывает возможность запустить первый скрипт страницы без nonce.
- Виджет считает модель, а отметка Chromium — сохранённый и перепроверяемый тестом результат браузера. Ввод своего заголовка не запускает его в настоящем документе.
- Политика default может преобразовать голую строку. Pass-through default или другая политика, возвращающая ввод без изменений, не очищает HTML.
- В проверенной Vue 3.5 политика vue пропускает v-html без очистки. Разрешение имени vue сохраняет этот путь; запрет может сломать статические HTML-вставки шаблонов.

</details>

<details>
<summary><b>Детали</b> — справочник ограничений</summary>

- report-only не блокирует от своего имени; другая enforce-политика продолжает действовать. Отсутствие отчётов не доказывает отсутствие нарушений.
- На стенде доставка report-to серверу не наблюдалась: тело снято из ReportingObserver, формат POST указан по Reporting API.
- Отчёт может содержать полный URL ресурса и строку запроса; сборщик должен учитывать возможные секреты в логах.
- Матрица, консоль, meta и фреймворки проверяются в указанном Chromium; поведение Firefox и WebKit эта тема не измеряет.

</details>

# Web Push

- Web Push доставляет сообщение через push-сервис браузера и Service Worker, даже когда страница не открыта. Это отдельный канал от живого соединения вкладки с сервером.
- Пользователь должен разрешить уведомления, а приложение — получить подписку и связать её с нужным получателем. Подписка и endpoint требуют аккуратного хранения и управления сроком жизни.
- VAPID подтверждает отправителя перед push-сервисом; шифрование содержимого защищает тело для получателя. Подписать отправку и зашифровать данные — разные операции.
- Service Worker получает ограниченное время на событие push. Асинхронную работу нужно связать с жизненным циклом события и выполнить необходимые требования показа уведомления.
- Push не гарантирует точное время или безусловную доставку. Обрабатывайте истёкшие подписки, повторы и переход по уведомлению, а важное состояние восстанавливайте из надёжного источника.

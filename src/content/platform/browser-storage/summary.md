# Хранилища браузера

- Хранилища браузера отличаются доступом, форматом и сроком жизни: cookie, Web Storage, IndexedDB, Cache API и OPFS не являются взаимозаменяемыми словарями.
- Обычная область данных связана с origin; sessionStorage дополнительно связан с вкладкой. Во встроенном контексте могут действовать разделение по верхнему сайту и ограничения доступа.
- `localStorage` синхронен и хранит строки. Для больших структур и транзакционных изменений чаще нужен асинхронный механизм, например IndexedDB.
- Жизненный цикл транзакции IndexedDB зависит от активности и очереди запросов. Ожидание произвольного внешнего события не гарантирует, что продолжение сможет добавить запрос в прежнюю транзакцию.
- Квоты, очистка пользователем и вытеснение не позволяют считать браузерное хранилище вечным. Серверные данные должны восстанавливаться, а незаменимые локальные документы требуют экспорта или резервной копии.

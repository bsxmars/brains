# iframe: чужой и свой документ внутри страницы

<details>
<summary><b>Ядро</b> — документ и границы доступа</summary>

- Iframe создаёт отдельный документ. SOP решает, можно ли читать его DOM; sandbox отнимает способности; allow делегирует отдельные API. Ни один из этих механизмов не заменяет остальные.
- Чужой origin сохраняет границу доступа, даже если allow-same-origin оставил ему собственный источник. Этот флаг не выдаёт источник родителя.
- Сообщение через postMessage проверяют по origin, конкретному source и допустимой форме data.

</details>

<details>
<summary><b>Карта</b> — практические договоры</summary>

- [Встраивание](/platform/iframe/#s1): src или srcdoc, доступное имя, размеры и отложенная загрузка.
- [Свой и чужой](/platform/iframe/#s2): contentDocument, урезанный WindowProxy и отдельные встроенные объекты.
- [Сообщения](/platform/iframe/#s3): точный targetOrigin, проверка отправителя, рукопожатие ready.
- [Песочница](/platform/iframe/#s4): непрозрачный источник, флаги и снятие sandbox собственным srcdoc.
- [Права](/platform/iframe/#s5): allow, поддержка Permissions-Policy, referrerpolicy и credentialless.
- [Высота](/platform/iframe/#s6): ResizeObserver внутри → проверенное сообщение → height снаружи.
- [История и фокус](/platform/iframe/#s7): переходы и клавиатура остаются частью поведения всей вкладки.

</details>

<details>
<summary><b>Подвох</b> — где одного флага мало</summary>

- Srcdoc наследует origin родителя, если sandbox не назначил opaque origin. Недоверенный HTML без песочницы получает права вашей страницы.
- Allow-scripts вместе с allow-same-origin опасны именно для содержимого своего origin: оно может снять атрибут и перезагрузиться.
- Sandbox не является сетевым фильтром. Для загрузок ресурсов нужна собственная CSP.
- Lazy может начать загрузку до появления фрейма на экране; порог выбирает браузер. Без JavaScript отложенная загрузка не применяется.
- Credentialless без поддержки становится обычным iframe: отправку кук тогда определяют обычные правила, а не игнорируемый атрибут.

</details>

<details>
<summary><b>Детали</b> — границы стенда</summary>

- Native-демо исполняет пробы в браузере читателя; таблицы отдельно сняты в Chromium 153, Firefox 155 и WebKit 26.6 Playwright.
- Родительский Permissions-Policy: fullscreen=() на стенде применил Chromium. Firefox/WebKit оставили fullscreenEnabled=true даже при том же заголовке.
- Отдельный процесс или поток не следует из одного наличия iframe. Замер таймера описывает конкретный режим запуска.
- Пример resize принимает только конечную высоту 0–10 000 px; предел выбран приложением, а не стандартом iframe.

</details>

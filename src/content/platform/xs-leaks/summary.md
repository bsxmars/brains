# XS-Leaks

`platform/xs-leaks` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** межсайтовая утечка одного бита: чужая страница не читает ваш ответ, а замечает признак — загрузился ли, сколько фреймов, было ли перенаправление.
- **Зачем:** SOP сторожит содержимое, а не последствия; одного бита хватает, чтобы узнать о человеке лишнее («вошёл ли он в эту клинику»), а повторяя запросы, из битов складывают строку.
- **Как работает:** утечке нужны три звена, защита рвёт одно:
  - запрос уходит с куками — рвут `SameSite` и политика изоляции по Fetch Metadata;
  - ответ зависит от пользователя;
  - разница видна чужой странице — рвут CORP, COOP, `frame-ancestors`, разделение кеша.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Защита работает, когда то, что видит чужая страница, одинаково для всех: одинаковый отказ ничего не выдаёт → «раздел Один бит вместо ответа».
- Классы: число фреймов, событие загрузки, навигация, кеш, размер и время, Resource Timing, ошибки ORB — ни один механизм не закрывает все → «раздел Классы утечек».
- `Sec-Fetch-Site/Mode/Dest/User` ставит браузер, подделать нельзя; `iframe` и `POST`-форма — тоже навигация → «раздел Fetch Metadata».
- Политика изоляции: свой сайт и переходы `GET` пропустить, открытый список, остальное с чужого сайта — 403 → «раздел Политика изоляции».
- CORP, COOP, `frame-ancestors`: сервер отвечает, браузер не показывает; запрос доходит всегда → «раздел CORP, COOP, frame-ancestors».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- По http заголовков `Sec-Fetch-*` нет — политика молча пропускает всё.
- CORP только на `200`, а `302` на вход без него — `onerror` против `onload` снова выдаёт состояние.
- COOP `same-origin` рвёт связь и со своими страницами без COOP — включать на всём сайте разом; `same-site` пускает ненадёжные поддомены.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Ветки политики: `no-metadata`, `own-site`, `navigation`, `public-path`, `cross-site` → «раздел Политика изоляции».
- На ответе политики — `Vary: Sec-Fetch-Site, Sec-Fetch-Mode, Sec-Fetch-Dest`; внедрять сначала журналом → «раздел Политика изоляции».
- После разрыва COOP окно для открывшего `closed: true`, у окна `opener === null` → «раздел CORP, COOP, frame-ancestors».
- При `frame-ancestors` браузер `X-Frame-Options` не смотрит → «раздел CORP, COOP, frame-ancestors».
- `Timing-Allow-Origin: *` на личных ответах открывает размеры и фазы → «раздел Тонкие места».

</details>

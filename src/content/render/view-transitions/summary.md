# View Transitions: анимация между состояниями

- View Transitions анимирует представления старого и нового состояний, а изменение DOM остаётся обязанностью приложения. API не выбирает новый маршрут или данные вместо него.
- Сначала захватывается старое состояние, затем выполняется callback обновления и подготавливается новое. Начало анимации и завершение изменения DOM отмечаются разными Promise.
- Имена переходов связывают соответствующие элементы. Они должны быть согласованными и не создавать неоднозначные совпадения в одном состоянии.
- Пропуск анимации не означает откат DOM: callback обновления всё равно должен корректно выполнить свою работу. Ошибки обновления и отказ анимации обрабатывают отдельно.
- Предусмотрите reduced motion, отсутствие поддержки и быстро повторённые переходы. Полезная анимация не должна задерживать основное действие или становиться условием корректности интерфейса.

# Критический путь и Web Vitals

- Пользователь ждёт не только сеть: для видимого результата нужны данные, стили и время браузера на обработку и рисование. Оптимизируйте критическую цепочку нужного состояния.
- LCP описывает появление крупного содержимого, INP — задержку реакции на взаимодействия, CLS — неожиданные сдвиги. Они характеризуют разные проблемы и не заменяют друг друга.
- Раннее обнаружение важного ресурса помогает только при правильном приоритете и отсутствии более длинного препятствия дальше по цепочке. Полученные байты ещё нужно декодировать и показать.
- Долгий JavaScript и очередь работы могут задержать реакцию после нажатия. Разделение задач полезно, если уменьшает ожидание пользователя, а не просто переносит вычисление.
- Сначала найдите длинный участок в измерении и свяжите его с причиной. Лабораторная трасса объясняет конкретный запуск, а полевые данные показывают распределение условий настоящих пользователей.

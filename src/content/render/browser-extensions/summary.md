# Расширения браузера и изолированные миры

- Расширение выполняет код с отдельными полномочиями и жизненным циклом. Его поведение определяется разрешениями, контекстом запуска и правилами браузера.
- Content script обычно работает в изолированном JS-мире, но взаимодействует с общим DOM страницы. Это позволяет изменять узлы без общего объекта window и прототипов JavaScript.
- Сообщения связывают страницу, content script и фоновые части. Проверяйте отправителя и данные на каждой границе; сообщение из DOM не становится доверенным автоматически.
- Фоновый Service Worker расширения может останавливаться и запускаться заново. Важное состояние и обработчики должны учитывать этот жизненный цикл.
- Расширение может изменить DOM, запросы и нагрузку до вашего кода. При ошибке только у части пользователей сравните чистый профиль, разрешения и контексты выполнения, не приписывая все изменения приложению.

# Картинки: загрузка, декодирование и выбор размера

`render/images` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** три цены картинки: байты, время старта и память битмапа.
- **Зачем:** файл выбирают до CSS по подсказкам из разметки; неверная подсказка молча везёт не тот файл.
- **Как работает:** слот из `sizes` → плотность = ширина файла / слот → первый с плотностью ≥ DPR → распаковка в битмап ш × в × 4 байта.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Без `sizes` слот `100vw`; `sizes="auto"` — только с lazy → «раздел srcset и sizes».
- `x`-дескрипторы; более плотный файл из кеша → «раздел x и кеш».
- `<picture>`: первый подошедший `<source>` по `type` и `media`; выбор формата сервером по `Accept` → «раздел picture».
- `quality` кодеков несравнима, сравнивают при равном PSNR → «раздел Форматы».
- Lazy ждёт раскладки, качается с запасом; приоритет — эвристика → «раздел lazy и приоритет».
- Уменьшение в CSS добавляет память; `img.decode()` распаковывает заранее → «раздел Память».
- `width`/`height` дают `aspect-ratio` и резервируют место → «раздел Место под картинку».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `loading="lazy"` на первом экране: парсер её пропускает, LCP растёт; `fetchpriority="high"` старт не ускоряет.
- Атрибуты без `height: auto` растягивают картинку.
- `<source>` с `min-width` по возрастанию: широкий экран застревает на первом.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Округления нет: слот 414 при DPR 1 берёт 800w → «раздел srcset и sizes».
- Около 41–42 дБ: JPEG 32 913, WebP 20 942, AVIF 7 432 байт → «раздел Форматы».
- Запас lazy: 3000 px на `4g`, до 8000 на `slow-2g` → «раздел lazy и приоритет».
- Битмап 1600×1067 — 6.8 МБ при любом формате → «раздел Память».
- Ошибки `decode()` — всегда `EncodingError` → «раздел Память».

</details>

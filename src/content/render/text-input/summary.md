# Ввод текста в браузере: события, IME и автозаполнение

- Клавиша, намерение изменить текст и готовое изменение — разные события. Вставка из буфера, автозаполнение, голос и IME не сводятся к keydown.
- `beforeinput` сообщает предполагаемую правку, input — результат изменения поля. Перед preventDefault проверяйте cancelable: некоторые шаги композиции IME нельзя отменить.
- Выделение и позиции API строки обычно используют UTF-16, а видимый символ может занимать несколько единиц. Не смешивайте индексы, кодовые точки и графемы.
- Программная запись value может заменить текст и изменить каретку, но не обязана воспроизводить цепочку пользовательских событий. Контролируемое поле должно согласовывать состояние с реальным вводом.
- Редактору нужны отдельные правила композиции, выделения и истории undo. Проверяйте реальные способы ввода, а не только печать латинской буквы с клавиатуры.

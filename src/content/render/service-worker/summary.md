# Service Worker изнутри

`render/service-worker` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** отдельный скрипт между страницами области и сетью; браузер ставит, хранит и будит его сам.
- **Зачем:** отвечать на запросы своей логикой.
- **Как работает:** `register()` → `install` (предзагрузка в кеш через `waitUntil`) → `waiting`, пока у старой версии есть управляемые вкладки → `activate` (чистка старых кешей) → `fetch` на каждый запрос.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Область по умолчанию — каталог скрипта; первая страница без контроллера → «раздел Регистрация и область».
- У каждой версии свой кеш, старый удаляют в `activate` → «раздел Установка и активация».
- F5 не освобождает вкладку; держат только управляемые вкладки → «раздел Почему новая ждёт».
- `skipWaiting` отменяет ожидание, `claim` забирает ничьи вкладки; вместе — новый воркер под старой страницей → «раздел skipWaiting и claim».
- Новая версия — другие байты `sw.js` или `importScripts` → «раздел Проверка обновления».
- `respondWith` только синхронно; три стратегии; navigation preload → «раздел Перехват fetch».
- Воркер засыпает и теряет переменные → «раздел Сон и пробуждение».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Один адрес с 404 в `PRECACHE` — установка проваливается (`redundant`), и все пользователи молча остаются на старой версии.
- `skipWaiting` + `claim` без перезагрузки: старый код просит файл, которого нет ни в новом кеше, ни на сервере.
- Предзагрузка без чтения `preloadResponse` — сервер получает страницу дважды.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Шире каталога — `SecurityError`, разрешает `Service-Worker-Allowed` → «раздел Регистрация и область».
- `updateViaCache: 'all'` прячет новую версию; `sw.js` отдавать с `no-cache` → «раздел Проверка обновления».
- Сон в Chromium — между 25 и 40 с простоя → «раздел Сон и пробуждение».
- `unregister()` не отпускает открытую вкладку до перезагрузки → «раздел Отладка».

</details>

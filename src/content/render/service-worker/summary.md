# Service Worker изнутри

`render/service-worker` · выжимка обновлена 2026-11-12.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** регистрация и версии отдельного скрипта, которым браузер управляет независимо от открытой страницы.
- **Зачем:** перехватывать запросы управляемых клиентов и выбирать ответ: сеть, кеш или запасная страница.
- **Как работает:** новая версия устанавливается, обычно ждёт освобождения старых клиентов и активируется. Сам процесс может останавливаться и запускаться заново между событиями; регистрация при этом остаётся.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Область регистрации выбирается по URL. Первая страница после `register()` обычно ещё без контроллера → «Регистрация и область».
- `event.waitUntil` включает подготовительные промисы в работу события. Кеши версий могут сосуществовать → «Установка и активация».
- F5 не гарантирует освобождение старой версии: новый документ снова может получить прежний контроллер → «Почему новая версия ждёт».
- `skipWaiting` позволяет активироваться при старых клиентах. `claim` назначает активный воркер контроллером подходящих клиентов области, в том числе неуправляемых → «skipWaiting и claim».
- Сравниваются байты скрипта и зависимостей, а не факт деплоя → «Проверка обновления».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Новый контроллер не обновляет уже загруженные HTML и JS страницы. Старый код может запросить удалённый файл старой версии.
- `respondWith` вызывают в обработчике события синхронно, передавая при необходимости промис ответа.
- Navigation preload без использования `preloadResponse` может продублировать сетевой запрос.
- Глобальные переменные не являются долговременным хранилищем; под отладчиком сон воркера может не воспроизвестись.

</details>

<details>
<summary><b>Детали</b> — смотреть в теме</summary>

- Офлайн работает только то, для чего код предусмотрел ответ без сети → «Без сети».
- Журнал `SwLab` вычисляет учебная модель; рядом — записанный журнал Chromium. В произвольном сценарии нового браузерного запуска нет.
- Cache Storage и IndexedDB переживают остановку процесса; конкретный срок простоя браузер не гарантирует → «Сон и пробуждение».
- `unregister()` не означает немедленного снятия контроллера с открытой страницы → «Отладка и залипший воркер».

</details>

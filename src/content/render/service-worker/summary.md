# Service Worker изнутри

- Service Worker — управляемый браузером обработчик событий с регистрацией и версиями. Он может работать без открытой страницы, но не является постоянно живым фоновым процессом.
- Установка, ожидание и активация новой версии — разные этапы. Открытые клиенты могут продолжать работать со старым worker; новая регистрация не гарантирует немедленную смену контроллера.
- Fetch-обработчик выбирает ответ из сети, Cache API или другой логики. Cache API не применяет автоматически все правила обычного HTTP-кеша.
- Версия приложения и кешированные ресурсы должны оставаться совместимыми. Принудительная активация может смешать старую страницу и новые правила, если переход не спроектирован.
- Асинхронную работу связывайте с жизненным циклом события и сохраняйте важное состояние вне памяти worker. Предусмотрите обновление, очистку кешей и восстановление, если сеть или хранилище недоступны.

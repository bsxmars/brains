# Каскад и вычисление стилей

`render/css-cascade` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** алгоритм шага style: из многих объявлений свойства выбрать одно значение.
- **Зачем:** у `color` много мнений (браузер, пользователь, автор, `style`, анимация, переход), а значение нужно одно.
- **Как работает:** шесть признаков подряд, следующий только при ничьей: этаж и `!important` → теневое дерево → `style` → слои → специфичность → порядок. Пустой каскад → наследование или initial. Затем computed, после раскладки used.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- `!important` переносит на другой этаж; у важных порядок слоёв перевёрнут → «раздел Шесть критериев».
- `@scope` добавил седьмой критерий, близость → «раздел Шесть критериев».
- Специфичность — тройка по разрядам; у `style` и `!important` её нет → «раздел Специфичность».
- `initial`, `unset`, `revert` берут значение из разных мест → «раздел Наследование».
- `getComputedStyle` отдаёт resolved value; для `width` нужна раскладка → «раздел Стадии значения».
- Цена style — сколько элементов помечено; `:has()` тянет пересчёт предка → «раздел Переменные и инвалидация».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Наследование не каскад: `#main { color: red }` не спорит с `a { color: blue }` на ссылке.
- Неверный тип в `var()` → IACVT → `unset`; прежнее объявление уже выброшено, фолбэк не спасает, спасает `@property`.
- Старый CSS в раннем слое: его `!important` бьёт всё.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Восемь этажей, сверху transition → «раздел Шесть критериев».
- `:is()`/`:not()` берут самый специфичный аргумент, `:where()` обнуляет, `&` равен `:is()` → «раздел Специфичность».
- `display: initial` даёт `inline`, `revert` — `block` → «раздел Наследование».
- Стадии: declared, cascaded, specified, computed, used, actual → «раздел Стадии значения».
- Recalculate Style, затем Elements affected, затем Selector Stats → «раздел Переменные и инвалидация».

</details>

# Каскад и вычисление стилей

- Каскад выбирает объявление свойства, а наследование и начальные значения заполняют остальные случаи. Наиболее специфичный селектор не всегда побеждает.
- До специфичности сравниваются происхождение, важность и другие ступени каскада, включая контекст теневого дерева и слой. Позднее объявление решает только при равенстве предшествующих критериев.
- Порядок слоёв позволяет явно управлять группами правил. Обычные и important-объявления имеют разные направления приоритета, поэтому слой нужно оценивать вместе с важностью.
- После выбора значение ещё вычисляется: подставляются var и разрешаются зависимости. Недопустимая подстановка не означает автоматический возврат к любому предыдущему объявлению.
- Для диагностики смотрите совпавшие правила, вычисленное и использованное значение. Каскад, наследование и ограничение размера при layout объясняют разные части результата.

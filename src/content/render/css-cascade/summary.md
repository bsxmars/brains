# Каскад и вычисление стилей

`render/css-cascade` · выжимка обновлена 2026-11-12. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** каскад выбирает объявление свойства для конкретного элемента; наследование и начальное значение заполняют то, что не задал выбранный стиль.
- **Порядок:** происхождение и важность, контекст теневого дерева, style, слой, специфичность, близость @scope и порядок. До следующего признака доходят при равенстве предыдущих.
- **После выбора:** значения вычисляются, var подставляется; размеры, зависящие от геометрии, уточняются при layout.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Обычные и важные объявления меняют порядок слоёв → «Почему победило именно это правило».
- Специфичность — тройка, сравниваемая по разрядам; is/not/has берут максимум аргументов, where даёт ноль → «Специфичность».
- inherit, initial, unset, revert и revert-layer выбирают разные источники значения → «Наследование».
- getComputedStyle возвращает resolved value по правилам конкретного свойства → «Стадии значения».
- Подстановка переменных, @property, :has и область инвалидации → «Переменные и инвалидация».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Невалидное значение после var не возвращает проигравшее объявление в каскад: padding получает начальный 0.
- Цвет относится к used value CSSOM, хотя в примере совпадает с computed и не требует геометрии.
- Специфичность родителя не соревнуется с правилом самого ребёнка: наследование — отдельный механизм.

</details>

<summary><b>Детали</b> — не учить, смотреть в теме</summary>

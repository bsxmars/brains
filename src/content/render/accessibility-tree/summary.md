# Дерево доступности: что видит скринридер

`render/accessibility-tree` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** второе дерево рядом с DOM: у узла роль, имя, состояния; скринридер читает только его.
- **Зачем:** чего нет в дереве, для незрячего нет на странице, а мышью таких ошибок не заметить.
- **Как работает:** обход DOM → скрытое выпадает с поддеревом → роль из тега или `role` → имя по accname (побеждает первый непустой источник) → обёртки без роли и имени пропускаются, их дети остаются в дереве.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- `display: none`, `visibility`, `hidden`, `inert`, `aria-hidden` убирают узел → «раздел Что попадает».
- Неявная роль зависит от контекста (`<a>` без `href`, `<section>` без имени) → «раздел Роль».
- Порядок источников имени: `aria-labelledby` → `aria-label` → родной HTML → содержимое → `title` → «раздел Имя».
- `role="button"` — только табличка в дереве, без фокуса и клавиш → «раздел div с onclick».
- `tabindex`: 0, -1, положительный → «раздел Фокус и Tab».
- Живые регионы: `aria-live`, `status`, `alert` → «раздел Живые регионы».
- Chromium, Playwright и axe считают по-своему → «раздел Кто считает».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `aria-hidden` на фокусируемом: узла нет в дереве, а Tab на него попадает.
- Неверный `id` в `aria-labelledby` и опечатка в `role` молча игнорируются; `aria-label` заглушает видимый текст.
- Регион, вставленный вместе с текстом, молчит: пустой регион ставят заранее. Tab идёт по DOM, а не по экрану.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Шаги accname 2A–2I → «раздел Имя».
- Кнопка: Enter жмёт на `keydown`, пробел на `keyup` → «раздел div с onclick».
- Положительные `tabindex` идут первыми по возрастанию, потом нули по документу → «раздел Фокус и Tab».
- `<label for>` и `aria-labelledby` не пересекают границу Shadow DOM → «раздел Имя».
- `status` и `<output>`: `polite` и `atomic: true`; `alert` — `assertive` → «раздел Живые регионы».

</details>

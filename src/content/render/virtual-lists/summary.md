# Длинные списки: виртуализация

`render/virtual-lists` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** в DOM только окно видимых строк плюс запас, остальная высота — пустые распорки.
- **Зачем:** каждый узел хранится, стилизуется и раскладывается — цена растёт с длиной списка, хотя видно строк двадцать.
- **Как работает:** по `scrollTop` считается `[start, end)` плюс overscan; распорки держат полосу прокрутки; при разной высоте — префиксные суммы, бинарный поиск, `ResizeObserver`, поправка прокрутки.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Полный DOM и `content-visibility` платят за строку списка, окно — за строку экрана; на прокрутке наоборот → «раздел Цена узла».
- Распорки в потоке совместимы с якорением, `transform` — нет → «раздел Окно».
- Строка выше окна выросла — сдвинуть прокрутку на разницу; библиотеки выключают якорение → «раздел Разная высота».
- `content-visibility: auto` — окно без JS, нужен `contain-intrinsic-size` → «раздел content-visibility».
- Поиск, диктор и фокус видят только DOM → «раздел Доступность и поиск».
- Липкий заголовок добавляют в окно; подгрузка по близости `end` к концу → «раздел Заголовки и подгрузка».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `content-visibility` без запасного размера удорожает первый кадр.
- `scrollTop += delta` при якорении — двойная поправка.
- Перерисовка через `innerHTML` убивает якорь и фокус — узлы по ключу.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- 10 000 строк: 50 011 узлов против 102 → «раздел Цена узла».
- Без запасного размера: раскладка ×1.3–1.4, стиль ×2.4–2.5 → «раздел content-visibility».
- 17 сравнений на 100 000 смещений; дерево Фенвика → «раздел Разная высота».
- `aria-setsize`/`aria-posinset`, `aria-rowcount`/`aria-rowindex` → «раздел Доступность и поиск».
- Запас 3–5 строк не спасает прыжок ползунком → «раздел Окно».

</details>

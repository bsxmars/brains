# Длинные списки: виртуализация

- Виртуальный список держит в DOM только видимый диапазон и небольшой запас. Распорки сохраняют общую геометрию, хотя большинства строк в документе нет.
- При известной одинаковой высоте диапазон вычисляется из scrollTop. Для разной высоты нужны накопленные смещения, поиск строки и обновление после измерений.
- Overscan снижает риск пустого края при движении, но увеличивает работу. Подбирайте его под скорость прокрутки и стоимость строки, а не делайте бесконечным запасом.
- Стабильный ключ связывает данные и экземпляр строки при переиспользовании. Локальное состояние, фокус и выделение нельзя безусловно привязывать к текущей позиции DOM-элемента.
- Виртуализация не делает дешёвыми сортировку, загрузку и обработку всех данных. Поиск по странице, доступность, изменяющиеся высоты и восстановление позиции требуют отдельного проектирования.

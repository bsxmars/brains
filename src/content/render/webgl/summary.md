# WebGL и конвейер GPU

- WebGL рисует пиксели внутри canvas по данным и шейдерам. Браузер размещает сам canvas через CSS, а приложение отвечает за содержимое сцены.
- Вершины проходят преобразование, растеризация определяет фрагменты, затем работают фрагментный шейдер, проверки глубины и смешивание. Сцена не становится деревом DOM-элементов.
- Буферы, текстуры, shader-программы и состояние вызовов должны быть согласованы. Проверяйте компиляцию, связывание, размеры viewport и формат входных данных.
- Стоимость зависит не только от числа фигур: важны площадь пикселей, передачи данных, состояние и число вызовов рисования. Чтение результата обратно на CPU может создавать ожидание.
- Попадание указателя, доступность и восстановление после потери контекста не возникают из готовой картинки автоматически. Храните восстанавливаемую сцену и освобождайте GPU-ресурсы по сроку жизни.

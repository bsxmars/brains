# Наблюдатели: Intersection, Resize, Mutation

`render/observers` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** три API, которые браузер зовёт сам при смене DOM, размера или видимости, каждое в своём месте цикла событий.
- **Зачем:** вместо чтения `getBoundingClientRect()` в `scroll`/`resize` — пачка записей в момент, когда ответ уже известен.
- **Как работает:** MutationObserver — микрозадача сразу после правки, без размеров. ResizeObserver — в кадре после `rAF` и раскладки, кругами только вглубь. IntersectionObserver считается в кадре, а колбэк — отдельная задача после кадра.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- IntersectionObserver позже даже `setTimeout` из колбэка ResizeObserver → «раздел Место в кадре».
- Запись приходит только при смене ступеньки порогов; первая — всегда после `observe()` → «раздел Пересечения».
- v2: `isVisible` — не перекрыта и не прозрачна, против подсунутых кликов → «раздел Пересечения».
- Три коробки ResizeObserver; `box` решает, на что реагировать; `transform` и сдвиг не видны → «раздел Размеры».
- `textContent` — это `childList`; стили и анимации записей не дают → «раздел Изменения DOM».
- `loading="lazy"` для картинок, `@container` вместо ResizeObserver, если ответ — CSS → «раздел Применения».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Видимая цель — `isIntersecting: false`, пока ratio ниже первого порога (во всех трёх движках).
- Лента со сторожем останавливается: сторож остался в зоне, ступенька та же — лечится `unobserve` + `observe`.
- Колбэк ResizeObserver меняет свою же цель — `ResizeObserver loop completed…`; менять можно только детей.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Порядок: задача → MutationObserver → микрозадача → `setTimeout` → кадр: `rAF` → ResizeObserver → IntersectionObserver → «раздел Место в кадре».
- Начальная ступенька −1, начальный размер −1×−1 → «разделы Пересечения, Размеры».
- `rootMargin`: только `px`/`%`; Chromium округляет пиксели вниз, проценты к нулю → «раздел Пересечения».
- v2: `trackVisibility` требует `delay` ≥ 100 мс, иначе `NotSupportedError` → «раздел Пересечения».
- `disconnect()` теряет недоставленное, спасает `takeRecords()` → «раздел Изменения DOM».

</details>

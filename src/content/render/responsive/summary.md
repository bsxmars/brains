# Адаптивность изнутри

`render/responsive` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** три вопроса к браузеру: ширина окна (`@media`, `vw`), место компонента (`@container`, `cqi`), настройка человека (`rem`, `em`).
- **Зачем:** у каждого ответа своя точка отсчёта; почти все ошибки адаптивности — вопрос, заданный не тому.
- **Как работает:** мета-тег задаёт layout viewport, щипок и клавиатура двигают только visual viewport. Медиазапрос проверяется до стилей страницы: окно с полосой прокрутки, `em` от шрифта браузера. Контейнерный запрос спрашивает ближайшего предка-контейнера, `em` — от его шрифта.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Без `<meta viewport>` телефон верстает на 980; layout против visual viewport, слушать `visualViewport` → «раздел Вьюпорт».
- `vh` = большой вьюпорт, `svh`/`dvh`; `100vw` включает полосу прокрутки → «раздел Единицы окна».
- Запись диапазоном без щели; `prefers-*`, `hover`, `pointer` → «раздел Медиазапросы».
- `container-type` даёт изоляцию размера: элемент «по содержимому» схлопывается → «раздел Контейнеры».
- Выбор контейнера по имени, себя не спрашивает, style-запросы → «раздел Контейнеры».
- Текст на `vw` не растёт при масштабе страницы (WCAG 1.4.4) → «раздел clamp и масштаб».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `html { font-size: 62.5% }` не двигает `40em` в `@media`, а настройка шрифта браузера двигает.
- Опечатка в имени контейнера молчит: правило просто не срабатывает.
- Решать «мобильная или нет» по `clientWidth` — разойдётся с `@media` на полосу; брать `matchMedia`.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Pixel 7: без meta 980 и масштаб 0.42, текст около 6.7px → «раздел Вьюпорт».
- Chromium 153: `scrollbar-gutter`/`overflow-y: scroll` не уменьшают `vw`, вопреки спецификации → «раздел Единицы окна».
- Контейнер меряется по content-box; `cqi` без контейнера — от окна → «раздел Контейнеры».
- `style(color: red)` не срабатывает никогда, только переменные → «раздел Контейнеры».
- Масштаб 400% на 1280 = окно 320 (WCAG 1.4.10) → «раздел clamp и масштаб».

</details>

# Адаптивность изнутри

`render/responsive` · выжимка обновлена 2026-11-12.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** выбор размера относительно окна, места компонента или шрифта.
- **Зачем:** одна карточка в узкой колонке и широкой ленте должна подстраиваться к своему месту, хотя окно у них общее.
- **Как работает:** `@media` спрашивает окно и устройство, `@container` — подходящего предка. Layout viewport задаёт вёрстку, visual viewport показывает, какая её часть видна.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- `meta viewport` позволяет телефону раскладывать страницу по доступной ширине; число 980 — наблюдение мобильного стенда → «Вьюпорт».
- Щипок уменьшает видимую область в CSS-координатах без перестройки layout viewport; масштаб страницы через меню работает иначе.
- `svh`, `lvh`, `dvh` различают состояния браузерных панелей; экранная клавиатура управляется отдельными правилами → «Единицы окна».
- `em` в `@media` берётся из начального шрифта браузера, в size container query — из шрифта контейнера → «Медиазапросы», «Контейнерные запросы».
- Размер контейнера не должен зависеть от того же содержимого, которое меняет запрос: containment разрывает эту зависимость.

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `html { font-size: 20px }` не сдвигает медиазапрос `40em` так, как изменение начального шрифта браузера.
- `100vw` и ширина без классической полосы прокрутки могут различаться.
- Текст только на `vw` может сохранять физический размер при увеличении масштаба страницы. Наличие `rem` в clamp само по себе не доказывает двукратного увеличения текста.

</details>

<details>
<summary><b>Детали</b> — смотреть в теме</summary>

- Style-запросы и поддержка конкретных возможностей привязаны к движку и версии стенда.
- `cqi` выбирает подходящего контейнерного предка; отсутствие подходящего контейнера имеет определённый fallback.
- Демо вычисляет ограниченный набор правил из показанного CSS и сравнивает их с реальной карточкой → «Какое правило сработает и почему».
- Проверка 320 CSS-пикселей важна и для телефона, и для увеличенного масштаба; условия доступности разобраны в «clamp() и масштаб страницы».

</details>

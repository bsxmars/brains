# События DOM: захват, всплытие и делегирование

- У события есть заранее построенный путь через дерево. Доставка проходит захват, цель и при разрешённом bubbles — всплытие; слушатели на одном узле могут иметь разные настройки.
- StopPropagation останавливает переход по пути, stopImmediatePropagation — ещё и следующие слушатели на текущем узле. Они не означают отмену стандартного действия элемента.
- PreventDefault работает только у отменяемого события и с учётом passive. Стандартное действие и его момент зависят от события; активация флажка, например, имеет особые правила.
- Делегирование использует путь события, а не отдельный слушатель для каждого потомка. Target может меняться на границе Shadow DOM; composedPath и composed имеют собственные роли.
- Синтетический вызов и настоящее пользовательское действие различаются доверием и разрешёнными возможностями. Удаляйте слушатели вместе с владельцем и не делайте вывод о жесте пользователя только по вызову обработчика.

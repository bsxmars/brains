# События DOM: захват, всплытие и делегирование

`render/dom-events` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** событие идёт по пути от `window` до самого глубокого узла и обратно; каждый узел может слушать, остановить или отменить.
- **Зачем:** на этом стоят делегирование, остановки, отмена и граница веб-компонентов.
- **Как работает:** путь считается один раз до первого слушателя → захват сверху вниз (`capture: true`) → цель: сначала захватные, потом остальные → всплытие вверх, если `bubbles` → действие по умолчанию, если никто не вызвал `preventDefault`.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- `target` стоит на месте, `currentTarget` меняется → «раздел Путь и фазы».
- `stopPropagation` пускает соседей по узлу, `stopImmediatePropagation` — нет; `preventDefault` путь не трогает → «раздел Остановки».
- Синтетический `submit`/`keydown` ничего не делает, `click` — делает; `isTrusted` → «раздел Действие по умолчанию».
- Делегирование: `closest` + `contains`; не всплывающие события — через `focusin` или захват → «раздел Делегирование».
- Колесо и касания на `window`/`document`/`html`/`body` пассивны по умолчанию → «раздел passive».
- `dispatchEvent` и `el.click()` синхронны — другой порядок микрозадач → «раздел Синхронно».
- Подмена цели на хозяина, `composed`, `composedPath()` → «раздел Shadow DOM».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `preventDefault` без `cancelable` или в пассивном слушателе молча не действует.
- После `await` у события `currentTarget` — `null`, отмена уже опоздала.
- `new Event` по умолчанию не всплывает, не отменяется и не выходит из Shadow DOM.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- `eventPhase`: 1 захват, 2 цель, 3 всплытие → «раздел Путь и фазы».
- Флажок ставит галочку до слушателей и откатывает при отмене; ссылка меняет адрес после → «раздел Действие по умолчанию».
- `form.submit()` — без события и проверки; `requestSubmit()` — со слушателями → «раздел Действие по умолчанию».
- Настоящий клик — семь событий, `el.click()` — одно → «раздел Синхронно».
- happy-dom расходится с Chromium в Shadow DOM, пассивности и состоянии после отправки → «раздел Отправка как код».

</details>

# Раскладка изнутри: flex и grid

`render/layout-internals` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** алгоритмы спецификации, по которым flex и grid на шаге layout делят место.
- **Зачем:** почти все сюрпризы (неравные `flex: 1`, вылезающая ссылка) идут из min-content; зная алгоритм, переполнение предсказывают, а не лечат наугад.
- **Как работает:** flex: базовый размер (`flex-basis` → `width` → max-content) → расти или сжиматься → раздать по `flex-grow` или `flex-shrink` × базовый → упёршихся в min/max заморозить, остаток делить заново. Grid: вычесть фиксированные треки и `gap`, остаток по `fr`; трек с долей меньше min-content становится фиксированным.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- min-content и max-content; `fit-content` — формула из них → «раздел Размеры содержимого».
- `flex: 1` (всё по долям) против `flex: auto` (делится только остаток после содержимого) → «раздел Рост».
- Автоматический минимум флекс-элемента = min-content; у элемента с `overflow` не `visible` его нет → «раздел Сжатие и min-width».
- Почему `overflow-wrap: anywhere` даёт ссылке сжаться, а `break-word` нет → «раздел Сжатие и min-width».
- `1fr` = `minmax(auto, 1fr)`; `auto-fill` против `auto-fit` → «раздел Треки и fr».
- Курсор авторасстановки идёт только вперёд; `dense` заполняет дыры → «раздел Авторасстановка».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- Во вложенном флексе `min-width: 0` нужен на **каждом** уровне: минимум внешнего — min-content внутреннего.
- `overflow: hidden` ради скругления углов вдруг даёт колонке сжиматься.
- `dense` меняет порядок на экране, но Tab и диктор идут по DOM.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- `fit-content` = `min(max-content, max(min-content, доступно))` → «раздел Размеры содержимого».
- `flex: 1` → `1 1 0%`, `flex: auto` → `1 1 auto`, `flex: none` → `0 0 auto` → «раздел Рост».
- Флекс `0.25` → 200/200, грид `0.25fr` → 150/150 в 600 px → «раздел Треки и fr».
- Chromium хранит координаты в 1/64 px → «раздел Тонкие места».

</details>

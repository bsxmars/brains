    Дешёвой анимацию делает не свойство само по себе, а то, **куда браузер её отдал**.
    Композитной анимации главный поток не нужен вовсе: ни стиль, ни раскладка, ни отрисовка

    занят.

  </Callout>

  Когда вы пишете `animation: move 1s`, браузер решает, может ли он посчитать всю анимацию
  без вашего потока. Для этого должны сойтись три вещи: траектория известна заранее,
  все анимируемые свойства из короткого списка, у элемента есть слой, который можно двигать.
  Сошлись — анимация уходит на композитор. Нет — каждый кадр её считает главный поток,
  тот же, где выполняется ваш JavaScript.

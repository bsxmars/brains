# Шрифты и текст: от загрузки до пикселей

`render/fonts-text` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** путь веб-шрифта от `@font-face` до глифов.
- **Зачем:** файл приходит позже текста; подмена перекладывает строки и двигает всё ниже (CLS).
- **Как работает:** раскладке нужен символ → запрос → `font-display` решает, что видно (блокировка, подмена) → файл пришёл, строки раскладываются заново → шейпер даёт глифы с кернингом и лигатурами.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- `visibility: hidden` шрифт тянет, `display: none` нет → «раздел Когда шрифт качается».
- Шрифт выбирается для каждого символа отдельно → «раздел Когда шрифт качается».
- Пять значений `font-display`, FOIT и FOUT → «раздел font-display».
- Запасной шрифт с подогнанными метриками даёт нулевой сдвиг → «раздел Сдвиг при подмене».
- `unicode-range`: качаются только нужные тексту подмножества → «раздел Подмножества».
- `preload` с `crossorigin`; `document.fonts`: `status`, `check`, `load`, `ready` → «раздел preload и document.fonts».
- Ширина слова не равна сумме букв; `measureText` даёт тот же шейпинг → «раздел Ширина строки».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- `block` не спасает от сдвига: невидимый текст уже разложен метриками запасного.
- `preload` без `crossorigin` — два скачивания. `optional` без preload в Chromium не покажет шрифт на первом заходе.
- `check()` отвечает `true` на опечатку в имени; `measureText` до загрузки молча мерит запасной шрифт.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Блокировка/подмена: `block` 3 с/∞, `swap` 0/∞, `fallback` 100 мс/3 с, `optional` 100 мс/0, `auto` в Chromium 2 с/∞ → «раздел font-display».
- Для Georgia: `size-adjust: 92.21%`, `ascent-override: 79.71%`, `descent-override: 28.74%`; CLS 0.0387 → 0 → «раздел Сдвиг при подмене».
- Подгонка верна для одного кегля из-за оси `opsz` → «раздел Сдвиг при подмене».
- Пробел, цифры и знаки живут в latin, поэтому «Привет мир» качает оба файла → «раздел Подмножества».
- `AVATAR`: 149.31 против суммы 164.95 → «раздел Ширина строки».

</details>

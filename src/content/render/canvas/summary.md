# Canvas 2D и OffscreenCanvas: рисовать вне DOM

`render/canvas` · выжимка составлена с ИИ 2026-10-29 по тексту темы. Ключ ответа: сначала расскажи тему сам за 2 минуты, не глядя, потом открывай.

<details>
<summary><b>Ядро</b> — что нужно помнить</summary>

- **Что это:** элемент с одним буфером пикселей, который красят командами контекста 2D.
- **Зачем:** тысячи фигур без тысяч узлов со стилями и раскладкой; цена — попадание, фокус, доступность и чёткость делаете сами.
- **Как работает:** буфер = CSS-размер × DPR, `setTransform(dpr…)`; путь набирают после `beginPath`, рисуют `stroke`/`fill`; в кадре — `clearRect` и перерисовка; неподвижное — в готовый битмап; можно отдать холст воркеру.

</details>

<details>
<summary><b>Карта</b> — знать, что это существует</summary>

- Клик приходит на холст целиком, попадание — `isPointInPath`; текст на холсте не виден скринридеру → «раздел Битмап, а не дерево».
- Атрибуты и CSS — два несвязанных размера; присвоить `width` = стереть всё → «раздел Два размера холста».
- Обводка лежит по обе стороны линии пути, отсюда серые края → «раздел Полпикселя».
- `save`/`restore` не трогают путь; `clearRect` подчиняется матрице → «раздел Состояние и путь».
- Кеш в `OffscreenCanvas`, слои из холстов, `willReadFrequently` → «раздел Цена кадра».
- Чужая картинка без CORS пачкает холст → «раздел Чужие пиксели».
- `transferControlToOffscreen`, `ImageBitmap` → «раздел Холст в воркере».

</details>

<details>
<summary><b>Подвох</b> — крайние случаи и частые ошибки</summary>

- «Прибавьте 0.5» верно только для нечётной толщины в точках буфера; на DPR 1.5 чёткой линии в 1px нет.
- Без `beginPath` путь копится: полупрозрачное темнеет, работа растёт каждый кадр.
- `crossOrigin` без заголовка на сервере — картинка не грузится вовсе.

</details>

<details>
<summary><b>Детали</b> — не учить, смотреть в теме</summary>

- Буфер по умолчанию 300×150 → «раздел Два размера холста».
- 800×600 при DPR 3 — 17,3 МБ, память растёт как квадрат DPR → «раздел Два размера холста».
- Четыре обводки с альфой 0.25: `1 − 0.75ⁿ` → «раздел Состояние и путь».
- Присвоить `width` снимает пятно в Chromium и WebKit, не в Firefox → «раздел Чужие пиксели».
- Главный поток занят 1 с: воркер ~60 кадров, страница 0 → «раздел Холст в воркере».

</details>
